在 UKU Web 中，数字传单是一种在线促销页面，可以展示多个商品并分享给顾客。本页面介绍如何创建一个新的传单容器，设置基本信息，并保存为草稿。

## 创建新传单

要创建一个新的数字传单，请按照以下步骤操作：

<Steps>
  <Step title="进入数字传单页面">
    打开 UKU Web (<a href="https://web.ukuapp.com">web.ukuapp.com</a>) 并登录您的账户。从主菜单导航到 "数字传单" 部分。您会看到现有传单的列表，以及用于创建新传单的按钮。点击 "新传单" 或 "创建传单" 开始新传单的创建过程。
  </Step>
  <Step title="填写传单标题">
    输入传单的标题。标题是必填项，将显示在传单的顶部，并用于在列表中识别此传单。选择一个描述性的标题，例如 "三月促销活动" 或 "周末特价"。标题应简洁明了，让顾客一眼就能了解传单的主题。
  </Step>
  <Step title="设置开始和结束日期">
    选择传单的开始日期和结束日期。这些日期定义了传单的促销周期。开始日期是传单生效的日期，结束日期是传单失效的日期。请确保选择正确的日期，因为这会影响传单的可见性和排序。
  </Step>
  <Step title="选择模板">
    UKU 提供了多种传单模板供您选择。浏览可用模板并选择最适合您促销风格的一个。模板决定了传单的整体布局和设计。某些模板可能更适合特定类型的促销，例如节日促销或清仓大甩卖。
  </Step>
  <Step title="保持 Pubblicato 关闭">
    在创建草稿阶段，请确保 "Pubblicato"（已发布）开关处于**关闭**状态。这会将传单保存为草稿，允许您在发布前进行编辑和完善。您可以随时返回并继续编辑草稿，直到满意为止。
  </Step>
  <Step title="保存传单">
    点击"保存"按钮保存传单。传单将作为草稿保存，并出现在您的传单列表中。您可以随时点击它以继续编辑。
  </Step>
</Steps>

## 传单状态说明

| 状态 | 说明 |
| --- | --- |
| 草稿 | "Pubblicato" 开关关闭，只有您可以查看和编辑 |
| 已发布 | "Pubblicato" 开关打开，顾客可以通过链接查看 |

<Tip>
  建议先在草稿状态下完成所有编辑和检查，确认无误后再发布。这样可以避免顾客看到不完整或有错误的内容。
</Tip>

## 编辑已保存的传单

要编辑已保存的传单（无论是草稿还是已发布）：

1. 从数字传单列表中找到要编辑的传单
2. 点击传单的标题或编辑按钮
3. 修改需要更改的信息
4. 点击保存

<Warning>
  对于已发布的传单，某些修改可能不会立即生效，可能需要刷新页面才能看到更新后的内容。
</Warning>

## 重要提示

- 标题是必填项，不能为空
- 日期范围可以根据需要调整
- 在发布前，请仔细检查所有信息
- 草稿状态下的传单不会对外可见，您可以放心编辑
