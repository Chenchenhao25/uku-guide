在创建数字传单后，您需要添加具体的产品信息。本页面介绍如何向传单中添加单个产品，包括填写产品详情、设置价格和上传图片。

## 添加单个产品

要将产品添加到数字传单中，请按照以下步骤操作：

<Steps>
  <Step title="进入产品添加页面">
    打开您要编辑的数字传单（草稿状态）。在传单编辑页面中，找到并点击 "添加产品" 或 "+" 按钮。这将打开一个新的产品添加表单，供您输入该产品的详细信息。
  </Step>
  <Step title="填写产品名称">
    在 "产品名称" 字段中输入产品的名称。请使用清晰、简洁的名称，让顾客能够轻松识别产品。例如，"新鲜牛奶 1L" 或 "意大利面 500g"。产品名称是必填项，不能为空。
  </Step>
  <Step title="添加产品描述（可选）">
    在 "描述" 字段中输入产品的额外信息。这可以包括产品的特点、产地、保质期或其他相关信息。描述是可选的，但建议填写，因为它可以帮助顾客更好地了解产品。
  </Step>
  <Step title="设置价格">
    输入产品的促销价格。如果产品有原价和促销价的区别，请确保填写正确的价格。价格应准确无误，避免引起顾客误解。请查看应用内的最新价格信息以获取当前定价详情。
  </Step>
  <Step title="输入条码">
    在 "条码" 字段中输入产品的条形码。条码用于识别产品，确保每个产品的条码唯一。您可以使用条码扫描器扫描产品上的条码，或手动输入条码数字。
  </Step>
  <Step title="上传产品图片">
    点击 "上传图片" 按钮选择产品图片。支持常见的图片格式，如 JPG、PNG 等。选择一张清晰、明亮的产品照片，以便顾客能够清楚地看到产品的外观。
  </Step>
  <Step title="裁剪图片">
    上传图片后，您可能需要调整图片的显示区域。使用裁剪工具选择图片中最重要的部分。确保产品在裁剪后的图片中居中且清晰可见。调整完成后，保存裁剪设置。
  </Step>
  <Step title="保存产品">
    确认所有信息填写正确后，点击 "保存" 按钮将产品添加到传单中。产品将显示在传单的列表中，您可以继续添加更多产品或编辑现有产品。
  </Step>
</Steps>

## 产品信息字段说明

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 产品名称 | 是 | 产品的显示名称 |
| 描述 | 否 | 额外的产品信息 |
| 价格 | 是 | 促销价格 |
| 条码 | 是 | 产品唯一识别码 |
| 图片 | 是 | 产品照片 |

<Tip>
  建议为每个产品使用高质量的图片，裁剪时确保产品主体在画面中央。良好的图片可以提高顾客的购买意愿。
</Tip>

## 编辑和删除产品

如果您需要修改已添加的产品信息：

1. 在传单编辑页面中找到该产品
2. 点击产品旁边的 "编辑" 按钮
3. 修改需要更改的信息
4. 点击保存

要删除产品：

1. 找到要删除的产品
2. 点击产品旁边的 "删除" 按钮
3. 在弹出的确认对话框中确认删除

<Warning>
  删除产品后，该产品将从传单中移除，且无法恢复。如果只是想暂时不显示某个产品，可以考虑将其从传单中移除而不是删除。
</Warning>

## 图片建议

- 使用光线充足、背景干净的图片
- 确保产品占据图片的主要部分
- 避免使用模糊或过度曝光的图片
- 图片格式建议使用 JPG 或 PNG
- 上传前可以在电脑上预览图片效果
