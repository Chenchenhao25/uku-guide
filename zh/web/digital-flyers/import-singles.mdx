如果您之前已经创建了单个促销产品，UKU Web 提供了便捷的导入功能，可以将这些促销产品快速添加到有多个产品的数字传单中，避免重复输入。

## 从单个促销导入

此功能允许您从现有的单个促销中选择并导入到当前编辑的数字传单。

<Steps>
  <Step title="打开导入功能">
    在数字传单的编辑页面中，找到并点击 "导入" 或 "从单个促销导入" 按钮。系统将显示一个弹窗或新页面，列出您之前创建的所有单个促销产品。
  </Step>
  <Step title="选择要导入的产品">
    浏览列表中的单个促销产品，选择您想要导入到当前传单中的产品。您可以通过滚动列表查看所有可用的单个促销。每个产品通常会显示名称、价格和图片预览，方便您识别。
  </Step>
  <Step title="确认导入">
    选择完产品后，点击 "导入" 或 "确认" 按钮。选中的产品将被复制到当前数字传单中，包括产品名称、描述、价格、条码和图片等信息。
  </Step>
  <Step title="检查导入结果">
    导入完成后，返回传单编辑页面检查导入的产品。确认所有信息正确无误。如有需要，您可以编辑这些产品以调整显示效果。
  </Step>
</Steps>

## 批量导入

如果您有大量单个促销需要导入，可以使用批量导入功能提高效率。

<Steps>
  <Step title="进入批量导入模式">
    在导入页面中，查找 "批量导入" 或 "批量选择" 选项。这通常以一个复选框或多选界面呈现，允许您同时选择多个产品。
  </Step>
  <Step title="搜索筛选产品">
    使用搜索框输入关键词快速找到特定产品。您可以按产品名称、条码或其他标识进行搜索。搜索功能可以帮助您在长列表中快速定位目标产品，节省时间。
  </Step>
  <Step title="批量选择">
    勾选您要导入的所有产品。某些界面可能提供 "全选" 功能，但请谨慎使用，确保只选择真正需要导入的产品。
  </Step>
  <Step title="执行批量导入">
    点击 "批量导入" 按钮。系统将一次性导入所有选中的产品到当前数字传单中。请耐心等待导入完成，具体时间取决于您选择的产品数量。
  </Step>
</Steps>

## 搜索功能

搜索功能可以帮助您在大量单个促销中快速找到目标产品：

- 在导入页面的搜索框中输入关键词
- 支持按产品名称搜索
- 支持按条码搜索
- 搜索结果会实时显示，无需额外点击

<Tip>
  如果搜索结果为空，请检查关键词拼写是否正确，或尝试使用更短的关键词进行模糊搜索。
</Tip>

## 导入注意事项

| 情况 | 处理方式 |
| --- | --- |
| 产品已存在于当前传单 | 系统可能会提示重复，您可以选择跳过或覆盖 |
| 图片导入失败 | 检查图片格式和大小，或稍后手动重新上传 |
| 价格信息不一致 | 导入后请仔细核对并手动调整价格 |

<Warning>
  导入操作会将单个促销的信息复制到数字传单中，但不会删除或影响原始的单个促销。导入后，两个版本将独立存在，修改其中一个不会影响另一个。
</Warning>

## 导入后的调整

导入完成后，建议进行以下检查和调整：

1. 核对产品顺序，确保重要的促销产品排在前面
2. 检查产品图片是否正确显示
3. 确认价格信息准确无误
4. 根据需要微调产品描述
5. 保存所有更改
