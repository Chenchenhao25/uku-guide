UKU Web 提供了一些辅助工具，帮助您在线下宣传和管理客户数据合规性。本页面介绍如何打印 A4 海报和下载客户同意书模板，同时说明当前不可用的功能。

## 打印 A4 海报

UKU 可以生成适合 A4 纸张打印的宣传海报，方便您在商店或社区中张贴。

<Steps>
  <Step title="进入海报页面">
    在 UKU Web 中，导航到 "客户" 或 "工具" 部分。查找 "海报"、"A4 海报" 或 "打印海报" 相关选项。
  </Step>
  <Step title="选择海报内容">
    系统可能提供多种海报模板或内容选项。选择最适合您当前需求的海报样式，例如促销海报、新客优惠海报或订阅二维码海报。
  </Step>
  <Step title="预览海报">
    在打印前，预览海报的排版和内容。确认文字清晰、图片正确、联系信息无误。
  </Step>
  <Step title="打印设置">
    使用浏览器的打印功能（通常是 Ctrl+P 或 Command+P），选择 A4 纸张尺寸。建议：

    - 选择 "实际大小" 或 "100%" 缩放，避免内容被拉伸
    - 如果可用，选择 "高质量" 打印模式
    - 确认打印机中有足够的纸张
  </Step>
  <Step title="执行打印">
    点击 "打印" 按钮，等待打印机完成输出。检查打印效果，如有问题可调整设置后重新打印。
  </Step>
</Steps>

<Tip>
  建议使用白纸或浅色纸张打印海报，避免使用彩色纸张导致内容难以辨认。如果预算允许，可以使用稍厚的纸张（如 120g/m² 或更高）以提升质感。
</Tip>

## 下载同意书模板

根据数据保护法规，您可能需要收集客户同意才能向其发送促销信息。UKU 提供了同意书模板供您下载使用。

<Steps>
  <Step title="找到同意书模板">
    在 UKU Web 的客户管理区域，查找 "同意书"、"隐私同意" 或 "合规文档" 相关链接。
  </Step>
  <Step title="下载模板">
    点击 "下载" 按钮，将同意书模板保存到您的电脑。模板通常为 PDF 格式，包含了需要客户填写的标准条款。
  </Step>
  <Step title="打印使用">
    将下载的 PDF 文件打印出来，放置在收银台或服务台。新客户填写并签名后，代表同意接收您的促销信息。
  </Step>
</Steps>

<Note>
  同意书模板仅供参考，具体合规要求请咨询当地法律专业人士。根据您所在地区的法规，您可能需要对模板内容进行适当调整。
</Note>

## 当前不可用的功能

以下功能目前在 UKU Web 中**不可用**或**已禁用**：

### 导入 CSV（已禁用）

从 CSV 文件批量导入客户信息的功能目前已被禁用。这意味着：

- 您不能通过上传 CSV 文件一次性添加多个客户
- 所有新客户必须手动逐个添加
- 如果您有大量现有客户数据需要迁移，需要手动录入

<Tip>
  虽然 CSV 导入不可用，但您仍可以逐个手动添加客户。如需添加大量客户，建议分批进行，每天添加一部分，避免一次性输入过多信息导致疲劳出错。
</Tip>

### 批量发送

向多个客户同时发送消息的功能目前不可用：

- 不支持向客户群发短信或促销通知
- 每次联系需要单独进行（如果有此功能）
- 订阅二维码是目前主要的批量触达方式

| 功能 | 状态 | 替代方案 |
| --- | --- | --- |
| CSV 导入客户 | 已禁用 | 手动逐个添加 |
| 批量发送消息 | 不可用 | 使用二维码让顾客主动订阅 |
| 短信群发 | 不可用 | 依赖顾客扫码订阅后的推送 |

<Warning>
  请勿尝试使用第三方工具绕过 UKU 的限制批量导入或发送信息。这可能违反 UKU 的服务条款，并可能导致您的账户受到限制。
</Warning>

## 操作建议

在当前功能限制下，建议采取以下策略管理客户和推广：

1. **重点使用订阅二维码**：这是目前最高效的获客方式
2. **手动维护核心客户**：将最重要的客户信息手动录入通讯录
3. **打印海报宣传**：利用 A4 海报在店内和社区中宣传
4. **收集纸质同意书**：确保数据合规，保留客户签署的同意书原件
5. **定期更新信息**：手动更新客户信息，保持通讯录的准确性

<Note>
  UKU 可能会在后续版本重新启用 CSV 导入和批量发送功能。请关注 UKU 官方公告或管理员通知获取最新信息。
</Note>
