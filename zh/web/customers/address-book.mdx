---

UKU Web 提供了客户通讯录功能，帮助您记录和管理顾客的联系信息。这在进行促销活动通知、发送更新或建立客户关系时非常有用。

## 添加新客户

要向通讯录添加新客户，请按照以下步骤操作：

<Steps>
  <Step title="进入客户页面">
    在 UKU Web 中，从主菜单导航到 "客户" 或 "客户管理" 部分。您会看到现有的客户列表（如果有的话）。
  </Step>
  <Step title="点击添加客户">
    点击 "新客户"、"添加客户" 或 "+" 按钮，打开新客户添加表单。
  </Step>
  <Step title="填写姓名">
    在 "姓名" 字段中输入客户的姓名。姓名是**必填项**，不能为空。请使用客户的真实姓名或常用称呼，以便日后识别。
  </Step>
  <Step title="填写电话号码">
    在 "电话" 字段中输入客户的电话号码。电话号码也是**必填项**。确保输入正确的号码，包括区号，以便将来能够联系到客户。
  </Step>
  <Step title="填写其他信息（可选）">
    如果表单中有其他字段（如邮箱、地址、备注等），您可以选择填写。这些通常是可选的，但填写更多信息有助于更好地服务客户。
  </Step>
  <Step title="保存客户">
    确认信息无误后，点击 "保存" 按钮。新客户将被添加到您的通讯录中。
  </Step>
</Steps>

## 必填字段说明

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 姓名 | 是 | 客户的姓名或称呼 |
| 电话号码 | 是 | 客户的联系电话 |
| 邮箱 | 否 | 客户的电子邮件地址 |
| 地址 | 否 | 客户的住址或其他地址 |
| 备注 | 否 | 其他相关信息 |

<Warning>
  姓名和电话号码是必填项。如果未填写这两个字段，系统将无法保存新客户信息。请务必确保这两项信息准确无误。
</Warning>

## 搜索客户

当通讯录中的客户数量增多时，您可以使用搜索功能快速找到特定客户。

### 搜索方法

1. 在客户列表页面的顶部，找到搜索框
2. 输入客户姓名、电话号码或关键词
3. 系统会实时显示匹配的搜索结果
4. 点击搜索结果中的客户查看或编辑详情

<Tip>
  搜索功能支持模糊匹配，即使您只记得部分姓名或电话号码，也可以尝试搜索。系统会显示所有相关的结果供您选择。
</Tip>

## 编辑客户信息

如果客户的信息发生变化，您可以随时更新：

1. 在客户列表中找到该客户
2. 点击客户姓名旁边的 "编辑" 按钮
3. 修改需要更新的字段
4. 点击 "保存" 完成更新

## 删除客户

如果您需要从通讯录中移除某个客户：

1. 在客户列表中找到该客户
2. 点击 "删除" 按钮
3. 在弹出的确认框中确认删除

<Warning>
  删除客户后，该客户的所有信息将从通讯录中移除。此操作通常不可恢复，请谨慎操作。如果您只是暂时不需要联系某位客户，可以考虑将其保留在通讯录中。
</Warning>

## 客户数据管理建议

- 定期更新客户信息，确保电话号码等关键信息是最新的
- 尊重客户隐私，不要将客户信息用于未经同意的目的
- 定期备份重要的客户数据
- 使用备注字段记录客户的偏好或特殊需求
