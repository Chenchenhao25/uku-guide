从 Excel 或 CSV 文件导入是批量制作的最常见方式。只需要准备一张表格，就能一次创建几十甚至几百张海报。

## 准备文件

批量导入需要一张表格，至少包含条形码或商品名称。示例结构：

```text
条形码;名称;原价;折扣价
;意面 500 克;1.49;0.99
;洗衣液 1 升;3.50;2.79
```

<Warning>
  在 Excel 中，请把条形码列的格式设为 **文本**，避免长条形码被自动转成科学记数法（如 6.9E+12）。
</Warning>

## 导入步骤

<Steps>
  <Step title="打开批量">
    在左侧菜单进入 **批量**。
  </Step>
  <Step title="上传文件">
    点击 **加载 Excel/CSV**，或直接把文件拖拽到页面上。
  </Step>
  <Step title="映射列">
    在 **映射列** 窗口中，为条形码、名称、原价、折扣价指定对应的列。
  </Step>
  <Step title="跳过不需要的列">
    如果表格中有不用的列，选择 **不使用**。
  </Step>
  <Step title="至少关联条形码或名称">
    条形码和名称中必须至少映射一个，否则系统不知道商品是什么。
  </Step>
  <Step title="检查示例">
    映射窗口会显示每一列的示例数据。请检查是否正确对应。
  </Step>
  <Step title="应用映射">
    点击 **应用映射**，系统会把数据添加到批量的表格中。
  </Step>
  <Step title="确认表格">
    在批量的表格中检查新添加的行。
  </Step>
</Steps>

## 支持的字段

批量导入只识别以下 4 个字段：

| 字段 | 说明 |
| --- | --- |
| 条形码 | 商品的 EAN 或其他条形码 |
| 名称 | 商品的显示名称 |
| 原价 | 折扣前的价格 |
| 折扣价 | 促销价格 |

<Note>
  图片、有效期、模板等其他信息在后续步骤补充。批量导入只处理这四个基础字段。
</Note>

## 粘贴条形码

除了上传文件，还可以直接粘贴条形码列表：

<Steps>
  <Step title="打开条形码列表">
    在批量页面选择 **条形码列表** 输入方式。
  </Step>
  <Step title="粘贴条形码">
    每行一个条形码，或者从 Excel 复制多列（条形码、名称、价格）。
  </Step>
  <Step title="添加到表格">
    点击 **添加到表格**，条形码就会加入批量列表。
  </Step>
</Steps>

## 文件格式支持

| 格式 | 支持 |
| --- | --- |
| `.xlsx` | 支持 |
| `.csv` | 支持 |
| `.tsv` | 支持 |
| `.xls`（旧版） | 完整海报的导入不支持，批量通常也不建议使用 |

<Tip>
  推荐使用 `.xlsx` 或 `.csv` 格式。这两种格式最稳定，兼容性最好。
</Tip>

## 常见问题

<Accordion title="导入后条形码变成 6.9E+12">
  在 Excel 中把条形码列的格式设为 "文本"，然后重新输入或粘贴数据。
</Accordion>

<Accordion title="导入后价格是 0">
  检查表格中的价格是否使用了正确的小数点（点 或 逗号）。有些地区的 Excel 使用逗号作为小数点，可能导致解析失败。
</Accordion>

<Accordion title="导入的商品名称是乱码">
  CSV 文件的编码必须是 UTF-8。用 Excel 保存时选择 "CSV UTF-8" 格式。
</Accordion>
