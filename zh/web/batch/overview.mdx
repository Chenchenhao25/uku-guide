**批量** 功能可以通过一张共同的表格快速制作或更新大量单页海报。适合每周要更新几十上百张标签的中大型店铺。

## 批量能做什么

<CardGroup cols={2}>
  <Card title="批量创建" icon="plus">
    从 Excel、CSV、条形码列表或已有的商品出发，一次生成很多张海报。
  </Card>

  <Card title="批量更新" icon="arrows-rotate">
    修改多张已有海报的价格、有效期或图片，一次保存全部。
  </Card>

  <Card title="统一样式" icon="palette">
    对所有海报应用同一个模板、颜色和布局，保证视觉一致。
  </Card>

  <Card title="统一有效期" icon="calendar">
    为所有海报设置相同的开始日期和结束日期。
  </Card>
</CardGroup>

## 批量的商品来源

在批量页面，您可以从以下来源获取商品：

| 来源 | 适用场景 |
| --- | --- |
| Excel / CSV 文件 | 从供应商或收银系统导出的商品清单 |
| 粘贴的文字或条形码 | 手动扫描或复制来的条形码列表 |
| 待办产品 | 从手机上扫码收集的商品 |
| 数字海报 | 已经在数字海报中的商品 |
| 已有的单页海报 | 之前创建过的海报，可以复制或更新 |

详见 [导入文件](/zh/web/batch/import-file) 和 [从已有内容开始](/zh/web/batch/from-existing)。

## 批量 vs 完整海报

<Warning>
  这是两个 **完全不同** 的功能，请不要混淆。
</Warning>

| 特点 | 批量 | 完整海报 |
| --- | --- | --- |
| 结果类型 | 多张独立的单页海报 | 一份多页宣传册 |
| 输出格式 | 每张海报是一张图片 | 一个 PDF 文档 |
| 适用场景 | 价格标签、货架标签、批量促销 | 节日目录、季度宣传册 |
| 保存位置 | 服务器（可在手机和电脑之间同步） | 浏览器本地（需要备份） |

## 批量的基本流程

<Steps>
  <Step title="选择商品来源">
    从 Excel、条形码、待办或已有内容中选择。
  </Step>
  <Step title="完善商品数据">
    检查每一行的名称、价格，为需要的行添加图片。
  </Step>
  <Step title="应用样式和有效期">
    选择模板、编辑画布，然后一键应用到所有商品。
  </Step>
  <Step title="保存全部">
    点击 **保存全部**，等待完成。
  </Step>
  <Step title="处理错误行">
    修正有错误的行，重新保存。
  </Step>
</Steps>

## 何时选择批量

<Tip>
  当您需要一次处理 **超过 5 张** 海报时，批量比一张张创建要快得多。
</Tip>

<CardGroup cols={2}>
  <Card title="每周更新" icon="calendar-week">
    每周一次的促销更新，用批量导入 Excel 表格。
  </Card>

  <Card title="季末清仓" icon="tag">
    对大量商品同时打折，批量修改价格。
  </Card>

  <Card title="新品上架" icon="box">
    新到货的商品一起录入。
  </Card>
</CardGroup>
