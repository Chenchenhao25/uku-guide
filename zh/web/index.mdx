UKU Web 是一个面向意大利华人社区杂货店（idee）的网页管理平台，用于创建促销传单、管理库存、打印标签。此本地网站目前处于测试版本，可能与实际使用有差异。请参阅管理员发布的官方指南或观看 YouTube 教程视频：UKU APP。

UKU 提供三种下载和使用方式：通过 Telegram 机器人 (t.me/ukuappbot) 直接发送 PDF；通过 iOS 应用程序 (app.ukuapp.com) 下载并使用；或访问网页版 (web.ukuapp.com) 创建和管理促销单品。

---

## Web 与 iOS 的区别

Web 版主要用于批量管理促销单品和数字传单，而 iOS 版（见 [iOS 文档](/zh/ios)）支持扫描条码、打印标签和创建单个促销单品。两者数据互通，但 Web 版缺少 iOS 版的部分高级功能。

## 功能概览

UKU Web 主要功能包括：

- **数字传单**：创建和管理包含多产品的在线促销页面
- **电视循环播放**：将促销内容推送到连接电视的循环播放
- **客户管理**：维护客户通讯录和订阅二维码
- **订阅计划**：查看当前订阅状态和使用限额
- **库存管理**：查看和管理所有产品条码及库存

## 开始使用

1. 访问 [web.ukuapp.com](https://web.ukuapp.com)
2. 向下滚动页面找到登录/注册部分
3. 使用 UKU iOS 应用凭据或按照管理员提供的说明进行注册
4. 登录后进入仪表板管理您的杂货店

<Note>
  UKU 目前处于测试阶段，某些功能可能不完整或与预期不同。我们建议在发布前仔细检查所有设置。
</Note>
