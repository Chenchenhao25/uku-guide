如果您每天都会使用 UKU 网页版，可以把它保存为桌面快捷方式。这样双击图标就能打开，不用每次都在浏览器里输入地址。

## 如何保存

<Steps>
  <Step title="打开支持菜单">
    在 UKU 网页版中，进入 **设置 → 支持**。
  </Step>
  <Step title="点击保存到桌面">
    找到 **保存到桌面** 按钮并点击。
  </Step>
  <Step title="按浏览器提示操作">
    如果浏览器弹出安装窗口，按提示完成安装即可。

    如果没有弹出窗口，UKU 会显示对应浏览器的操作说明。
  </Step>
  <Step title="双击桌面图标测试">
    完成后，桌面会出现 UKU 图标。双击它就能直接打开 UKU 网页版。
  </Step>
</Steps>

## 各浏览器的安装方法

不同浏览器创建快捷方式的方式略有不同：

| 浏览器 | 操作 |
| --- | --- |
| Chrome | 点击右上角三个点 → 保存并分享 → 安装 UKU |
| Edge | 点击右上角三个点 → 应用 → 安装此站点为应用 |
| Safari | 文件 → 添加到程序坞（macOS） |
| Firefox | 需要手动在桌面创建快捷方式 |

## 快捷方式的功能

<Note>
  桌面快捷方式只是提供了一个 **快速打开的入口**。UKU 仍然需要联网才能使用大部分功能，快捷方式不会让 UKU 变成一个可以离线使用的应用。
</Note>

## 不再需要时

如果不再需要桌面快捷方式，直接把桌面上的图标拖到回收站即可删除。这不会影响您的 UKU 账户或数据。

## 更多入口方式

<CardGroup cols={2}>
  <Card title="浏览器书签" icon="bookmark">
    把 UKU 加入浏览器书签栏，也能快速打开。
  </Card>

  <Card title="搜索引擎" icon="magnifying-glass">
    在浏览器搜索 "UKU 网页版" 也能找到入口。
  </Card>
</CardGroup>

<Tip>
  推荐同时创建桌面快捷方式和浏览器书签，这样在任何情况下都能快速访问 UKU。
</Tip>
