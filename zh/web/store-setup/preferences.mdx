**店铺偏好** 里的设置决定了 UKU 如何显示价格、日期和内容语言。在开始批量创建海报前，请仔细检查这些选项。

## 打开店铺偏好

在左侧菜单进入 **设置 → 店铺偏好**。

## 主要偏好一览

| 偏好 | 作用 |
| --- | --- |
| 货币 | 决定所有价格的货币符号 |
| 内容和日期语言 | 影响本地化内容、模板文字和有效期文字 |
| 增值税税率 | 编辑器中含税/不含税计算的依据 |
| 小数点显示 | 决定最终价格中小数点的显示方式 |
| 记住海报设置 | 新建海报时自动使用上次的选择 |
| 从相册扫描 | 与手机 App 共享的图片选择偏好 |
| A4 打印安全边距 | 在打印时增加保护性空白 |

## 保存方式

<Note>
  下拉选择和开关类的偏好，修改后会 **自动同步保存**。请等待保存完成再离开页面。
</Note>

<Warning>
  店铺资料（名称、地址等）需要点击 **保存修改** 按钮才会保存，这与偏好设置不同。
</Warning>

## 关于货币的重要提示

<Warning>
  更改货币 **不会自动按汇率转换金额**。如果您把已有的内容切换到另一个货币，请手动检查每个价格是否合理。
</Warning>

例如：如果您的海报显示 10.00 EUR，切换到 CNY 之后，价格仍然是 10.00，只是货币符号变了。请手动更新价格数字。

## 语言选择

**内容和日期语言** 会影响：

- 完整海报模板中的默认文字
- "有效期" 等日期文字的显示方式
- 部分模板的本地化内容

<Tip>
  中国大陆的店铺通常选择：货币 CNY、内容语言 中文（简体）、增值税税率 0% 或根据实际情况填写。
</Tip>

## 记住海报设置

打开这个开关后，UKU 会记住您上次创建海报时的字体、颜色和模板选择，新建时直接使用这些设置，节省重复操作。

## A4 打印安全边距

启用这个选项后，A4 打印时会在页面边缘留出更多空白，避免文字被打印机切掉。

<Note>
  安全边距只对 **优惠 → 打印模式** 和相关功能生效。完整海报有自己的安全边距设置。
</Note>
