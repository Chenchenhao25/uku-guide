商品是完整海报的核心。每一个商品框都可以编辑名称、条形码、价格、图片和许多其他属性。价格还有多种显示样式可供选择。

## 编辑商品数据

<Steps>
  <Step title="点击商品框">
    在编辑器中点击要修改的商品框。
  </Step>
  <Step title="打开属性面板">
    右侧的属性面板会显示商品数据。
  </Step>
  <Step title="修改字段">
    修改名称、条形码、描述、原价、折扣价等字段。
  </Step>
  <Step title="选择增值税税率">
    如果该商品有单独的税率，请在这里填写。
  </Step>
</Steps>

## 主要字段

| 字段 | 说明 |
| --- | --- |
| 名称 | 显示在海报上的商品名称 |
| 条形码 | 用于识别和批量导入 |
| 描述 | 补充信息（可选） |
| 原价 | 折扣前价格 |
| 折扣价 | 促销价格 |
| 商品数量 | 例如 "500 克"、"1 升" |
| 增值税税率 | 该商品的税率 |
| 类别 | 用于分类和分页 |

## 价格显示样式

UKU 提供多种价格样式让促销更醒目：

<CardGroup cols={2}>
  <Card title="经典" icon="tag">
    原价加删除线，折扣价旁边。传统、清晰。
  </Card>

  <Card title="大号" icon="expand">
    折扣价字体特别大，视觉冲击力强。
  </Card>

  <Card title="徽章" icon="award">
    折扣价装在圆形或菱形徽章里，突出显示。
  </Card>

  <Card title="价签" icon="ticket">
    模拟纸质价签的样式，有传统店铺的感觉。
  </Card>

  <Card title="百分比" icon="percent">
    突出显示折扣百分比，例如 "-30%"。
  </Card>

  <Card title="拆分显示" icon="hashtag">
    整数部分和小数部分分开显示，例如 "9<sup>90</sup>"。
  </Card>
</CardGroup>

## 切换价格样式

<Steps>
  <Step title="选中商品">
    点击商品框，打开属性面板。
  </Step>
  <Step title="打开价格样式选择器">
    在价格区域找到 **样式** 选项。
  </Step>
  <Step title="预览各种样式">
    切换不同的样式，实时查看效果。
  </Step>
  <Step title="选择最合适的">
    选择最能突出您商品优势的样式。
  </Step>
</Steps>

## 显示项开关

除了价格样式，还可以控制显示哪些内容：

| 显示项 | 说明 |
| --- | --- |
| 原价 | 是否显示折扣前的价格 |
| 折扣百分比 | 是否显示折扣多少 |
| 条形码 | 是否显示条形码 |
| 有效期 | 是否显示促销时间 |
| 描述 | 是否显示补充说明 |
| 商品数量 | 是否显示规格 |

<Tip>
  显示项越多，信息越丰富，但也可能显得杂乱。建议根据商品的重要性调整：主打商品显示更多，一般商品保持简洁。
</Tip>

## 保持一致

为了让整份宣传册看起来协调：

<CardGroup cols={2}>
  <Card title="使用同类样式" icon="grip">
    同一页或同一类别的商品使用同一种价格样式。
  </Card>

  <Card title="控制颜色数量" icon="palette">
    整份宣传册使用 2-3 种主要颜色即可。
  </Card>
</CardGroup>

## 常见问题

<Accordion title="改了一个商品的价格样式，其他商品会变吗">
  不会。每个商品的样式是独立的。如果要统一，需要逐个修改，或者使用 [统一应用](/zh/web/batch/apply-style-dates)。
</Accordion>

<Accordion title="能自定义价格颜色吗">
  可以。选中商品后，在属性面板中修改 "价格颜色" 和 "背景颜色"。
</Accordion>

<Accordion title="价格显示不完整怎么办">
  可能是价格样式和商品框大小不匹配。尝试放大商品框，或者切换到更紧凑的样式。
</Accordion>
