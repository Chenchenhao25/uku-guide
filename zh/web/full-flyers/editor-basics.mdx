完整海报编辑器是您制作宣传册的主要工作台。熟悉它的两个视图、两个模式和右侧属性面板，能大幅提升工作效率。

## 两个视图

编辑器顶部有一个视图切换：

<CardGroup cols={2}>
  <Card title="排版视图" icon="table-cells">
    显示宣传册的每一页，可以看到实际排版效果。适合调整位置、颜色、图片。
  </Card>

  <Card title="商品视图" icon="list">
    显示所有商品的列表，可以快速修改数据、价格、类别。适合批量编辑数据。
  </Card>
</CardGroup>

### 何时用哪个视图

| 场景 | 推荐视图 |
| --- | --- |
| 调整某一页的布局 | 排版视图 |
| 修改多个商品的价格 | 商品视图 |
| 添加或删除商品 | 商品视图 |
| 更改字体或颜色 | 排版视图 |
| 检查最终打印效果 | 排版视图 |

## 两个模式

除了视图切换，编辑器还有 **基础** 和 **高级** 两种模式：

<CardGroup cols={2}>
  <Card title="基础模式" icon="star">
    显示最常用的选项，界面更简单。适合初学者。
  </Card>

  <Card title="高级模式" icon="wrench">
    显示所有可用选项，包括细节调整。适合有经验的用户。
  </Card>
</CardGroup>

<Tip>
  第一次使用完整海报时，建议留在基础模式。熟悉后再切换到高级模式解锁更多控制。
</Tip>

## 右侧属性面板

选中一个元素后，右侧的 **属性面板** 会显示相关设置。

### 常见的属性

| 元素 | 属性面板显示什么 |
| --- | --- |
| 商品框 | 名称、价格、图片、显示项、大小、位置 |
| 文字 | 内容、字体、颜色、大小、对齐 |
| 图片 | 位置、大小、旋转 |
| 页面 | 类型、背景、页眉、页脚 |
| 整份文档 | 格式、DPI、店铺资料 |

<Note>
  没有选中任何元素时，属性面板会显示整份文档的属性。选中一个元素后，就会切换到该元素的属性。
</Note>

## 编辑器界面的主要区域

<Steps>
  <Step title="顶部工具栏">
    保存、撤销、重做、视图切换、模式切换、导出等常用操作。
  </Step>
  <Step title="左侧页面缩略图">
    显示所有页面的缩略图，点击可以快速跳转。
  </Step>
  <Step title="中央画布">
    实际编辑区域。可以拖动元素、缩放页面、直接输入文字。
  </Step>
  <Step title="右侧属性面板">
    显示当前选中元素的可编辑属性。
  </Step>
</Steps>

## 常用键盘快捷键

| 快捷键 | 作用 |
| --- | --- |
| Ctrl / Cmd + S | 保存 |
| Ctrl / Cmd + Z | 撤销 |
| Ctrl / Cmd + Y | 重做 |
| Delete | 删除选中元素 |
| Ctrl / Cmd + C / V | 复制 / 粘贴 |
| 方向键 | 微调选中元素的位置 |

## 常见问题

<Accordion title="属性面板不显示怎么办">
  确认您已经选中了一个元素。如果面板整体收起，点击右侧的展开按钮。
</Accordion>

<Accordion title="切换到高级模式后属性变多了">
  这是正常的。高级模式显示所有可用属性。如果不需要这些选项，可以切回基础模式。
</Accordion>

<Accordion title="能同时打开多份宣传册吗">
  可以。在浏览器中打开多个标签页，每个标签页编辑一份宣传册。
</Accordion>
