**以往价格**（Prezzo precedente）是一个结构化字段，用于合规地显示商品在促销前的价格。欧盟 Omnibus 指令等法规要求商家在促销时明确标注以往价格。

## 什么是以往价格

<Note>
  以往价格与 **原价** 不同。原价是简单的划线价格，以往价格是符合法规要求的结构化数据，包括金额、参考基准、来源和期间。
</Note>

## 填写以往价格的字段

| 字段 | 说明 |
| --- | --- |
| 金额 | 具体的价格数字 |
| 基准 | 单价（例如每公斤、每升）用于对比 |
| 来源 | 从哪里获取的这个价格（例如上月最低价、常规售价） |
| 期间 | 该价格生效的时间段 |

## 填写步骤

<Steps>
  <Step title="选中商品">
    在编辑器中点击商品框。
  </Step>
  <Step title="打开以往价格部分">
    在属性面板找到 **以往价格** 选项。
  </Step>
  <Step title="启用以往价格">
    打开 **显示以往价格** 开关。
  </Step>
  <Step title="填写金额">
    输入商品之前的价格。
  </Step>
  <Step title="选择基准（可选）">
    如果需要单价对比，选择相应的基准单位。
  </Step>
  <Step title="选择来源">
    从下拉列表中选择价格来源，或填写自定义说明。
  </Step>
  <Step title="设置期间">
    填写该价格生效的日期范围。
  </Step>
</Steps>

## 为什么要结构化

<CardGroup cols={2}>
  <Card title="法规合规" icon="scale-balanced">
    欧盟 Omnibus 指令要求明确标注促销前 30 天的最低价格。
  </Card>

  <Card title="顾客信任" icon="handshake">
    透明的价格信息让顾客更相信促销的真实性。
  </Card>

  <Card title="避免罚款" icon="shield">
    错误的 "原价" 标注可能被消费者投诉或监管处罚。
  </Card>

  <Card title="易于审计" icon="magnifying-glass">

  </Card>
</CardGroup>

## 常见基准

| 基准 | 适用商品 |
| --- | --- |
| 每公斤 | 散装食品、称重商品 |
| 每升 | 液体（饮料、洗涤剂） |
| 每件 | 单件商品 |
| 每包 | 包装食品 |
| 每平方米 | 布料、面料 |

## 显示效果

在最终的宣传册上，以往价格通常显示为：

- **主要价格**：折扣价（大字）
- **以往价格**：例如 "此前 30 天最低价 12.50 元"（小字，通常带说明文字）

<Tip>
  以往价格的字体应该比折扣价小，但要清晰可读。建议使用中等大小和中性颜色。
</Tip>

## 常见问题

<Accordion title="以往价格必须填吗">
  在有 Omnibus 指令的地区（例如欧盟），是的。中国也有类似的价格透明度规定，建议主动填写。
</Accordion>

<Accordion title="以往价格能自动计算吗">
  不能。UKU 只是记录您填写的数据，不会自动计算 30 天最低价。请从您的销售系统中获取真实数据。
</Accordion>

<Accordion title="填错了以往价格会怎样">
  在合规角度可能构成误导性商业行为。请务必使用真实、可查证的价格。
</Accordion>

<Accordion title="能不显示以往价格吗">
  可以关闭显示开关。但如果您标注了 "促销" 字样，法规通常要求同时显示以往价格。
</Accordion>
