UKU 可以将您的促销内容推送到商店中的电视屏幕上循环播放。本页面介绍如何将电视设备与 UKU Web 连接，以便展示您的数字传单和促销内容。

## 准备工作

在开始连接之前，请确保：

- 您有一台可以访问互联网的智能电视或连接到电视的设备（如电视盒子）
- 电视设备可以打开网页浏览器
- 您的电脑和电视设备都连接到稳定的互联网

## 连接电视

要将电视与 UKU Web 连接，请按照以下步骤操作：

<Steps>
  <Step title="在电视上打开 UKU 电视页面">
    在电视设备的浏览器中，输入网址 <a href="https://tv.uku.to">tv.uku.to</a> 并打开。页面将显示一个配对码（通常是一串数字），以及用于输入此代码的界面。
  </Step>
  <Step title="在电脑上打开 UKU Web">
    在您的电脑上，使用浏览器访问 <a href="https://web.ukuapp.com">web.ukuapp.com</a> 并登录您的 UKU 账户。导航到 "电视" 或 "TV 循环播放" 部分。
  </Step>
  <Step title="输入配对码">
    在 UKU Web 的电视管理页面中，找到 "连接电视" 或 "添加电视" 按钮。点击后，系统会要求您输入电视上显示的配对码。仔细输入电视屏幕上显示的数字代码，确保没有输错。
  </Step>
  <Step title="确认连接">
    输入正确的配对码后，点击 "连接" 或 "配对" 按钮。如果代码正确，系统将确认连接成功，电视屏幕将开始显示您的 UKU 促销内容。
  </Step>
  <Step title="验证显示效果">
    回到电视屏幕前，确认内容是否正确显示。电视上应该会展示您已添加到 TV 循环中的促销图片和传单内容。
  </Step>
</Steps>

## 配对码说明

- 配对码是电视上显示的唯一数字代码
- 每个电视设备的配对码都不同
- 配对码通常会在一段时间后过期，如果过期需要刷新页面获取新的代码
- 输入时请仔细核对，避免因为输入错误导致连接失败

<Tip>
  建议在输入配对码时，让另一位同事在电视旁查看屏幕，以便确认配对码是否正确。
</Tip>

## 连接多台电视

如果您有多台电视需要连接：

1. 为每台电视重复上述步骤
2. 每台电视将获得不同的配对码
3. 在 UKU Web 中分别输入每台电视的配对码
4. 可以在电视管理页面中看到所有已连接的电视列表

## 常见问题

| 问题 | 解决方法 |
| --- | --- |
| 配对码无效或过期 | 刷新电视上的页面获取新配对码 |
| 无法打开 tv.uku.to | 检查电视的网络连接，确保可以访问互联网 |
| 连接成功但无内容显示 | 检查是否已将内容添加到 TV 循环中 |

<Warning>
  请确保电视设备连接到稳定的互联网。网络不稳定可能导致内容无法正常加载或播放。
</Warning>

## 断开连接

如果您需要断开电视连接：

1. 在 UKU Web 的电视管理页面中找到该电视
2. 点击 "断开连接" 或 "移除" 按钮
3. 确认操作

断开连接后，电视将不再显示 UKU 的促销内容，您可以随时重新连接。
