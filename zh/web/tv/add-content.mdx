连接电视后，您需要选择要在电视上循环播放的内容。UKU 支持将现有的促销内容和自定义图片推送到电视屏幕上展示。

## 添加现有促销内容

UKU 可以自动从您的促销产品中提取适合电视显示的横向内容。

<Steps>
  <Step title="进入电视内容管理">
    在 UKU Web 中，导航到 "电视" 或 "TV 循环播放" 部分。找到已连接的电视设备，点击进入内容管理页面。
  </Step>
  <Step title="选择来源">
    系统会显示可用的内容来源选项。选择 "现有促销" 或 "数字传单"，系统将列出您已创建的促销内容。
  </Step>
  <Step title="筛选横向内容">
    UKU 会自动识别适合电视显示的横向（横屏）内容。浏览器中可用的横向内容将以列表或缩略图形式显示。横向内容更适合电视屏幕的显示比例。
  </Step>
  <Step title="选择要显示的内容">
    从列表中选择您想要在电视上展示的内容。您可以选择多个项目，它们将按顺序循环播放。选择时请注意内容的视觉效果，确保在电视大屏幕上清晰可见。
  </Step>
  <Step title="确认添加">
    点击 "添加到 TV" 或 "确认" 按钮。选中的内容将被添加到该电视的播放列表中。
  </Step>
</Steps>

## 添加自定义图片

除了现有的促销内容，您还可以上传自己的图片到电视循环播放中。

<Steps>
  <Step title="进入自定义图片添加">
    在电视内容管理页面中，找到 "添加自定义图片" 或 "上传图片" 按钮。点击开始上传图片。
  </Step>
  <Step title="选择图片文件">
    从您的电脑中选择要上传的图片文件。支持的格式通常为 JPG、PNG 等常见图片格式。建议选择高分辨率、清晰的图片，以便在电视大屏幕上显示效果更好。
  </Step>
  <Step title="确认上传">
    点击 "上传" 按钮将图片发送到 UKU 服务器。上传完成后，图片会出现在内容列表中。
  </Step>
  <Step title="添加到播放列表">
    勾选新上传的图片，点击 "添加到 TV" 将其加入电视循环播放列表。
  </Step>
</Steps>

## 图片建议

为了在电视上获得最佳显示效果，请注意以下建议：

| 建议项目 | 说明 |
| --- | --- |
| 分辨率 | 使用高分辨率图片，避免模糊 |
| 比例 | 优先使用横向（16:9）比例的图片 |
| 内容清晰 | 文字要大且清晰，方便远处观看 |
| 颜色鲜明 | 使用对比度高的颜色组合 |
| 简洁明了 | 避免信息过多，突出重点 |

<Tip>
  电视通常距离观众较远，所以请确保图片中的文字足够大，价格和产品名称清晰可见。
</Tip>

## 内容排序

添加到 TV 的内容会按一定顺序播放：

1. 在电视内容管理页面中，您可以查看当前的播放顺序
2. 某些界面支持拖拽调整顺序
3. 新添加的内容通常会被追加到列表末尾
4. 系统会按照列表顺序循环播放所有内容

## 预览效果

在添加内容后，建议：

- 到电视前查看实际显示效果
- 确认文字大小是否适合远距离阅读
- 检查颜色在电视屏幕上是否清晰
- 如有问题，返回 UKU Web 调整或替换内容

<Warning>
  请查看应用内的最新价格信息，了解与 TV 内容数量相关的订阅限制。
</Warning>
