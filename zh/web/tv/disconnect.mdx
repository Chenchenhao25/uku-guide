当您需要更换电视设备、调整商店布局或解决显示问题时，可能需要断开电视与 UKU 的连接。本页面介绍如何断开连接、重新配对，以及处理常见的显示问题。

## 断开电视连接

要从 UKU 中断开某台电视的连接：

<Steps>
  <Step title="进入电视管理页面">
    在 UKU Web 中，导航到 "电视" 或 "TV 循环播放" 部分。您会看到所有已连接电视设备的列表。
  </Step>
  <Step title="选择要断开的电视">
    找到您想要断开连接的电视设备。列表中通常会显示电视的名称（如果有设置）或连接时间等信息，帮助您识别正确的设备。
  </Step>
  <Step title="点击断开按钮">
    在该电视条目旁边，点击 "断开连接"、"移除" 或类似的按钮。
  </Step>
  <Step title="确认操作">
    系统可能会弹出确认对话框，询问您是否确定要断开连接。点击 "确认" 完成操作。
  </Step>
</Steps>

断开连接后：

- 该电视将立即停止显示 UKU 的促销内容
- UKU Web 中不再显示此电视设备
- 电视屏幕上可能显示默认页面或空白

<Note>
  断开连接不会删除您上传到 UKU 的内容，只是停止向该电视推送。您可以随时重新连接此电视或其他电视。
</Note>

## 重新尝试配对

如果之前的配对失败，或您想重新连接已断开的电视：

<Steps>
  <Step title="刷新电视页面">
    在电视设备上，刷新浏览器页面或重新访问 <a href="https://tv.uku.to">tv.uku.to</a>。屏幕将显示一个新的配对码。
  </Step>
  <Step title="在 UKU Web 中重新连接">
    回到 UKU Web，进入电视管理页面，点击 "连接电视" 或 "添加电视"。
  </Step>
  <Step title="输入新配对码">
    输入电视上显示的新配对码，点击连接。
  </Step>
  <Step title="检查连接状态">
    如果连接成功，电视将开始显示内容。如果仍然失败，请检查网络连接或尝试重启电视设备。
  </Step>
</Steps>

## 电视屏幕不显示内容

如果您已成功连接，但电视屏幕上什么都不显示，请按以下步骤排查：

### 检查网络连接

- 确认电视设备已连接到互联网
- 尝试在电视上打开其他网页，确认浏览器可以正常访问互联网
- 如果网络不稳定，尝试重启路由器或电视的网络连接

### 检查内容是否已添加

- 在 UKU Web 中确认已为该电视添加了内容
- 检查内容是否处于 "激活" 状态
- 确认没有将所有内容都停用或移除

### 刷新电视页面

- 在电视上按 F5 或刷新按钮重新加载 <a href="https://tv.uku.to">tv.uku.to</a>
- 有时页面可能需要刷新才能正确同步

### 检查配对状态

- 在 UKU Web 的电视列表中，查看该电视的状态是否正常
- 如果显示异常，尝试断开并重新连接

| 可能原因 | 解决方法 |
| --- | --- |
| 网络断开 | 检查电视和路由器的网络连接 |
| 无激活内容 | 在 UKU Web 中激活至少一个内容 |
| 配对码过期 | 刷新电视页面获取新配对码并重新输入 |
| 浏览器问题 | 尝试关闭并重新打开电视上的浏览器 |

<Tip>
  如果以上方法都无效，可以尝试重启电视设备，然后重新访问 tv.uku.to 进行配对。
</Tip>

<Warning>
  某些老旧电视或电视盒子可能不支持 UKU TV 所需的网页技术。如果遇到兼容性问题，建议尝试使用不同的设备或浏览器。
</Warning>
