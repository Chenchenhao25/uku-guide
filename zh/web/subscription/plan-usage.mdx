**订阅** 页面显示您当前的方案、正在使用的资源量以及剩余额度。定期查看有助于避免因为超限而无法保存海报。

## 打开订阅页面

<Steps>
  <Step title="进入订阅">
    在左侧菜单选择 **订阅**。
  </Step>
  <Step title="查看方案、使用、管理三个部分">
    页面通常分为三部分：您当前的方案信息、已使用的资源、管理入口。
  </Step>
</Steps>

<Note>
  您也可以在 **设置 → 方案和限制** 中查看限制摘要。
</Note>

## 服务监控的资源

订阅方案通常包含以下资源限制：

| 资源 | 说明 |
| --- | --- |
| 每日创建单页 | 每天最多能创建多少张新的单页海报 |
| 数字海报数量 | 账户中最多能保留多少个数字海报 |
| 每个数字海报的商品数 | 单个数字海报最多能包含多少个商品 |
| 电视自定义图片 | 电视中最多能上传多少张自定义图片 |
| 未完成的待办 | 待办列表中最多能有多少个未完成任务 |

<Warning>
  本指南 **不列出具体数字**：不同方案的具体限制以 UKU 服务的实时返回为准。请以订阅页面显示的数字为准。
</Warning>

## 查看每种资源的详情

对每种资源，页面会显示：

- **已使用**：当前已经用了多少
- **限制**：您方案的上限
- **剩余**：还可以使用多少
- **重置时间**：例如每日创建单页会在第二天 00:00 重置

## 达到限制时会怎样

<Warning>
  达到每日创建上限后，当天无法继续创建新的单页海报。可以选择：
</Warning>

<CardGroup cols={2}>
  <Card title="等到次日重置" icon="clock">
    每日限制通常在午夜自动重置。
  </Card>

  <Card title="修改已有海报" icon="pen">
    修改和更新已有海报通常不占用新建额度。
  </Card>

  <Card title="升级方案" icon="crown">
    升级到更高级的方案，获得更高的限制。
  </Card>
</CardGroup>

## 常见问题

<Accordion title="不同订阅方案的限制是多少">
  具体数字请在订阅页面查看。UKU 会根据方案定期调整限制，具体以页面显示的为准。
</Accordion>

<Accordion title="批量制作也占用每日限制吗">
  是的，批量制作中每张新的海报都算作一次创建。修改已有海报通常不占用限制。
</Accordion>

<Accordion title="删除海报后限制会恢复吗">
  已经使用的额度不会因为删除而恢复。当日限制会在次日重置。
</Accordion>

<Accordion title="团队成员共享同一个限制吗">
  是的，同一个店铺账户下的所有用户共享同一个方案的限制。
</Accordion>
