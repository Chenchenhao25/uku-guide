**订阅 → 管理** 中可以升级方案、取消订阅或联系客服。UKU 通过 WhatsApp 与您沟通，点击相应按钮就会打开预设的联系方式。

## 主要操作

<CardGroup cols={2}>
  <Card title="升级方案" icon="arrow-up">
    联系客服讨论更适合您的方案。
  </Card>

  <Card title="联系支持" icon="headset">
    遇到问题时联系客服获取帮助。
  </Card>

  <Card title="取消订阅" icon="ban">
    发起取消订阅的请求。
  </Card>
</CardGroup>

<Warning>
  **点击这些按钮只是发起一个联系请求**。UKU 客服会通过 WhatsApp 与您沟通，实际的方案变更或取消需要与客服确认。
</Warning>

## 使用步骤

<Steps>
  <Step title="打开订阅管理">
    在左侧菜单选择 **订阅 → 管理**。
  </Step>
  <Step title="选择想做的操作">
    点击升级、支持或取消对应的按钮。
  </Step>
  <Step title="打开 WhatsApp">
    页面会自动打开 WhatsApp（网页版或桌面版）。
  </Step>
  <Step title="确认预设消息">
    通常会有一段预设的问候语。您可以直接发送，或在前面加上自己的问题。
  </Step>
  <Step title="等待客服回复">
    UKU 客服会在工作时间内回复您。
  </Step>
</Steps>

## 其他联系方式

除了通过订阅页面联系，您也可以：

- 在 **设置 → 支持** 菜单查看可用的联系方式
- 使用 WeChat 二维码（如果已加载）联系客服

<Tip>
  建议保存 UKU 客服的 WhatsApp 号码到通讯录，方便后续快速联系。
</Tip>

## 如何清晰描述问题

好的问题描述能让客服快速定位并解决问题。请提供以下信息：

<Steps>
  <Step title="指出所在的区块">
    例如 "在批量制作页面"、"在完整海报编辑器"。
  </Step>
  <Step title="描述执行的操作">
    例如 "上传 Excel 文件后点击应用映射"。
  </Step>
  <Step title="附上错误提示的原文">
    如果有错误弹窗，请截图或复制文字。
  </Step>
  <Step title="说明内容是否已保存">
    很重要：确认操作后数据是保存了还是丢失了。
  </Step>
  <Step title="附加相关信息（如适用）">
    对图形问题，说明海报格式和触发步骤。
  </Step>
</Steps>

## 问题描述示例

<Accordion title="好的描述">
  "在批量制作页面，我上传了一个包含 50 个商品的 Excel 文件（附截图）。点击应用映射后弹出错误 '无法解析价格列'。检查后发现价格使用了逗号作为小数点。如何调整？"
</Accordion>

<Accordion title="不好的描述">
  "批量不能用"、"报错了"、"这个功能有 bug"。
</Accordion>

## 常见支持场景

| 问题 | 联系方式 |
| --- | --- |
| 无法登录 | WhatsApp 客服 |
| 想升级或降级方案 | 订阅 → 升级 |
| 想取消订阅 | 订阅 → 取消 |
| 功能使用问题 | 设置 → 支持 |
| 数据丢失或错误 | 立即联系客服，附上具体商品/时间 |

## 常见问题

<Accordion title="点击取消订阅是否立即生效">
  不会。这只是打开与客服的联系。实际取消需要与客服确认，一般会说明生效时间。
</Accordion>

<Accordion title="升级订阅要多久生效">
  与客服确认支付后，通常会立即或短时间内生效。请以客服回复为准。
</Accordion>

<Accordion title="客服的回复时间">
  一般在工作时间内回复。如果需要紧急处理，请在消息中说明紧急程度。
</Accordion>
