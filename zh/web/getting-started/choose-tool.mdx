UKU 网页版有多个工具，每个工具适合不同的场景。本页面帮助您快速判断该用哪个。

## 快速选择表

| 目标 | 使用哪个 | 得到的结果 |
| --- | --- | --- |
| 为一个商品制作一张海报 | 横版 / 竖版 | 一张保存在 "优惠" 里的单页海报 |
| 一次制作很多张海报 | 批量 | 多张单页海报 |
| 修改已经做好的海报 | 优惠，或用批量修改多张 | 更新选中的单页 |
| 在一张 A4 纸上打印多张海报 | 优惠 → 打印模式 | A4 上多图排版 |
| 制作有很多商品和多页的宣传册 | 完整海报 | 可编辑的多页文档，可导出 PNG 和 PDF |
| 重复使用一套多页结构 | 完整海报模板 | 可用于新建文档的个人模板 |
| 通过链接分享多个优惠 | 数字海报 | 公开链接，可在手机上打开 |
| 在店内屏幕上展示优惠 | 电视 | 与电视关联的循环内容 |
| 处理手机上扫码收集的商品 | 待办产品 | 更新的任务和创建的海报 |
| 管理客户名录和订阅 | 客户 | 通讯录和订阅二维码 |

## 三个容易混淆的功能

### 批量 vs 完整海报

<Warning>
  **批量** 和 **完整海报** 做的事情完全不同。
</Warning>

- **批量**：一次生成或更新很多张 **单页海报**。每一张都是独立的图片。
- **完整海报**：把很多商品排在同一个 **多页宣传册** 里，形成一个 PDF 文档。

### 优惠的打印 vs 完整海报

- **优惠 → 打印模式**：把已经存在的单页海报图片，摆放在 A4 纸上打印。
- **完整海报**：制作一个多页宣传册，可以精细控制每一页的排版。

</Tip>
