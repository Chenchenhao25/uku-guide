登录后，UKU 网页版会显示主界面。本页面帮助您熟悉界面布局和常用操作。

## 左侧菜单

左侧的菜单栏可以访问所有主要功能。在电脑上，鼠标移到菜单上时它会自动展开显示完整名称。

主要区块包括：

| 区块 | 功能 |
| --- | --- |
| 仪表盘 | 快捷操作、最近的海报、店铺信息提示 |
| 横版 / 竖版 | 创建单页海报 |
| 优惠 | 管理所有已创建的海报 |
| 批量 | 通过表格批量创建或更新海报 |
| 完整海报 | 制作多页宣传册 |
| 数字海报 | 制作在线可分享的海报 |
| 电视 | 管理店内电视屏幕内容 |
| 客户 | 通讯录和二维码订阅 |
| 待办产品 | 未完成的产品制作任务 |
| 设置 | 店铺资料、偏好设置、订阅、支持 |

<Note>
  部分区块还有二级菜单。例如 **客户** 下有 **通讯录** 和 **订阅二维码**。
</Note>

## 仪表盘

登录后默认打开的是仪表盘。仪表盘上有：

- **快捷操作**：创建新的海报、跳转到最近使用的功能。
- **最近的海报**：您最近编辑的几张海报，方便快速回到工作。
- **店铺信息提示**：如果 Logo、地址或可见模板未填写，仪表盘会突出显示提醒。

<Tip>
  仪表盘的提示是查漏补缺的好帮手。第一次登录时请特别注意这些提示。
</Tip>

## 语言与主题

界面右上角通常有两个切换：

- **界面语言**：切换菜单和按钮的语言。
- **主题（明/暗）**：切换明亮主题或深色主题。

<Warning>
  界面语言和店铺内容语言是分开的。界面语言不会影响海报中的文字。海报文字的语言由 [店铺偏好设置](/zh/web/store-setup/preferences) 决定。
</Warning>

## 退出与会话恢复

要退出登录，请点击右上角的个人菜单，选择 **退出**。

### 会话过期的提示

如果您在使用过程中看到以下提示：

- **会话过期**
- **会话无效或已被撤销**

请重新登录。

### 无法加载店铺资料

如果看到与 "无法加载店铺资料" 相关的提示，通常是网络连接不稳定。请点击 **重试** 或检查网络后再操作。
