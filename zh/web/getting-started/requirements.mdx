UKU 网页版是为电脑设计的工作台。手机浏览器打开时会提示您使用手机 App。本页面告诉您开始前需要准备什么。

## 硬件与浏览器

<CardGroup cols={2}>
  <Card title="电脑" icon="desktop">
    台式机或笔记本电脑均可。屏幕越大越好，方便同时查看多张海报和产品列表。
  </Card>

  <Card title="现代浏览器" icon="browser">
    推荐使用 Chrome、Edge、Safari 或 Firefox 的最新版本。旧版浏览器可能无法正常显示编辑器。
  </Card>

  <Card title="稳定网络" icon="wifi">
    登录、保存海报、上传图片和背景移除都需要联网。网络中断时部分操作会失败。
  </Card>

  <Card title="店铺账户" icon="user">
    需要一个已注册的 UKU 店铺账户。手机 App 中注册的账户可直接在网页版使用。
  </Card>
</CardGroup>

## 打开网页版

在浏览器地址栏输入项目提供的 UKU 网页版地址。生产环境的域名是：

```text
https://web.ukuapp.com
```

<Note>
  如果您所在的环境使用了不同的地址，请以团队提供的为准。
</Note>

## 手机打开会怎样

UKU 网页版并未针对手机屏幕做优化。如果您在手机浏览器打开，登录页面会提示您改用手机 App。

请在手机上使用 UKU App，在电脑上使用网页版。详见 [选择合适的工具](/zh/web/getting-started/choose-tool)。

## 登录方式

有两种登录方式，您可以选择任意一种：

- [手机号 + 密码登录](/zh/web/getting-started/login-password)：适合独立在电脑上使用，无需借助手机。
- [扫码登录](/zh/web/getting-started/login-qr)：适合已经在手机上登录了 UKU App，希望快速在电脑上打开的场景。

<Tip>
  首次使用建议先在手机 App 完成注册和店铺基本信息填写，再登录网页版。这样登录后就能直接看到店铺数据。
</Tip>
