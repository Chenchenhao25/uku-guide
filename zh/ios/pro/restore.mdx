如果您之前已经购买过 Uku Pro，更换设备、重新安装应用或遇到订阅状态未同步的情况时，可以使用恢复购买功能找回您的订阅。本页说明操作步骤和重要限制。

## 何时使用恢复购买

以下情况适合使用恢复购买：

- 更换了新 iPhone 或 iPad
- 重新安装了 UKU 应用
- 订阅状态显示异常，刷新后仍未恢复
- 从免费版重新登录后 Pro 状态消失

## 恢复步骤

<Steps>
  <Step title="登录正确店铺">
    确保您已登录购买 Pro 时使用的那个 UKU 店铺账户。Pro 订阅与特定店铺绑定，不是与 Apple ID 单独绑定。
  </Step>
  <Step title="进入 Pro 页面">
    打开**个人资料**，点击 **Uku Pro** 入口。
  </Step>
  <Step title="点击恢复购买">
    在 Pro 页面找到**恢复购买**按钮并点击。系统会自动查询与该 Apple ID 关联的 UKU 订阅记录。
  </Step>
  <Step title="等待验证">
    应用会联系 Apple 服务器验证您的购买历史。这个过程需要网络连接，通常只需几秒到一分钟。
  </Step>
  <Step title="确认状态">
    验证完成后，检查页面是否显示 Pro 已激活。如果成功，您就可以继续使用完整功能。
  </Step>
</Steps>

## 重要限制

<Warning>
  恢复购买**不能**将订阅转移到另一个 UKU 店铺。如果您想为其他店铺使用 Pro，需要单独购买。
</Warning>

恢复购买仅适用于以下情况：

- 同一 Apple ID 下已购买的 UKU 订阅
- 登录的是购买时绑定的 UKU 店铺账户

以下情况恢复购买**无效**：

- 尝试将 Pro 转移到另一个 UKU 店铺
- 使用不同的 Apple ID 购买过，现在登录了另一个 Apple ID
- 订阅已被 Apple 官方取消或退款

## 恢复失败怎么办

如果恢复购买没有成功：

1. 确认设备登录的 Apple ID 与购买时一致
2. 检查网络连接是否正常
3. 确认 UKU 店铺账户正确
4. 前往 iPhone **设置** -> 您的姓名 -> **订阅**，确认 UKU 订阅仍然存在
5. 如果以上都正常但恢复仍失败，请联系 UKU 客服并提供 Apple 订阅截图

## 刷新状态

Pro 页面通常也有**刷新状态**按钮，用于重新同步订阅信息。如果恢复购买无效，可以先尝试刷新状态。
