## 买了但应用里还是免费版

按顺序试：

1. 等几分钟 —— 看到 **正在验证购买。我们会自动重试，无需再次购买。** 时，**千万不要再买一次**；
2. 订阅页面点 **刷新状态与订阅**；
3. 点 **恢复购买**；
4. 完全退出应用再打开；
5. 还不行就联系客服，带上 Apple 的收据。

提示 **暂时无法记录你的购买。付款是安全的：请点击刷新状态与订阅重试。** 意思是钱没问题，只是我们的服务器暂时没记下来。

## 提示「此 Apple ID 已有关联其他店铺的 UKU 订阅」

一个 Apple 账号的 UKU 订阅只能属于**第一家**用它购买的店铺。两家店都要 Pro：

- 用**另一个 Apple ID** 给第二家店买；
- 或者联系客服。

<Warning>
  如果购买已经完成，提示会写明：本次付款**已计入那家店**，当前店铺的方案没有变。不要重复购买，直接联系客服。
</Warning>

## 换了手机，Pro 不见了

用**同一个 Apple ID** 登录新手机，然后：**我的 → 升级 UKU Pro → 恢复购买**。

提示 **此订阅已关联其他 UKU 店铺。请登录购买时使用的店铺。** —— 这个订阅属于另一家店，用那家店的账号登录。

## 其他常见提示

| 提示 | 意思 / 怎么办 |
| --- | --- |
| 暂无可用订阅，请稍后重试。 | 价格没加载出来：点 **刷新状态与订阅** |
| 此设备已关闭 App 内购买。 | 去 **设置 > 屏幕使用时间 > 内容和隐私访问限制** 打开 |
| 此订阅在你的 Apple 账号所在国家或地区不可用。 | Apple ID 的国家不对 |
| 请在 Apple 账号设置中检查付款方式。 | 银行卡过期或余额不足 |
| 购买正在等待 Apple 批准。 | 开了家长批准：等对方同意 |
| 你的店铺已有 Pro。 | 客服手动给过 Pro：到期后再订阅 |
| 你的 Apple 订阅已生效。请通过管理订阅修改。 | 已经是 Pro 了 |

## 取消续订

**我的 → 管理订阅**，会跳到 Apple 的订阅设置。取消后应用里会显示 **自动续订已关闭。**，到期前 Pro 照常用。

<Note>
  订阅是在 **Apple** 那边收费和管理的。退款要向 Apple 申请，UKU 这边不能直接退。
</Note>
