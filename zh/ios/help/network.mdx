## 顶部的「无网络连接」横幅

> **无网络连接** — 显示上次连接时的数据

应用没有关闭，而是进入了**只能看、不能改**的状态。

| 没网时能做 | 没网时做不了 |
| --- | --- |
| 看已经看过的海报、传单、客户 | 保存新海报 |
| 看店铺资料 | 上传照片 |
| 浏览已缓存的模版 | 扫条码查商品 |
| — | 打印还没下载过的图片 |
| — | 连接电视、订阅 |

**怎么处理：** 打开 Wi-Fi 或移动数据，横幅会自己消失。横幅没了但内容还是旧的，在列表页往下拉刷新一下。

## 提示「连接错误。请检查网络连接并重试。」

那一刻网断了。检查一下：

- Wi-Fi 连上了但实际上不能上网（店里常见）；
- 移动数据是不是关着；
- 用手机浏览器打开一个网站试试。

## 提示「服务器错误。请稍后重试。」

这次是我们这边的问题，不是您的手机。等几分钟再试；一直这样就联系客服（附上截图和大概的时间）。

## 提示「%d 秒后重试」或英文 `Rate limit exceeded`

短时间内操作太密集，服务器请您慢一点。等提示里的秒数过去再试，不要连续猛点。

## 其他英文提示

这几句是应用里没翻译的技术提示：

| 英文 | 意思 |
| --- | --- |
| `No data received` | 服务器没返回内容：重试 |
| `Failed to decode response` | 回复读不懂：重试；持续出现联系客服 |
| `Invalid URL` | 内部错误：联系客服 |
| `Unauthorized. Please sign in again.` | 重新登录 |

## 店里网络本来就差

- 做海报时尽量用稳定的 Wi-Fi，上传照片最吃网络；
- 一次做很多张时，可以先用 **商品待办** 把条码扫下来，回家再做；
- 实在不行就用手机热点。
