把它在 [错误提示速查表](/zh/ios/help/errors) 里搜一下：整理了应用里几乎所有提示的含义和处理办法。

## 都解决不了

**首页 → 联系客服**：扫 **微信客服群** 或 **专属客服** 的二维码，也可以用 **WhatsApp**。

联系时请说清楚：

1. 您做了什么操作；
2. 屏幕上出现的原话（最好截图）；
3. 店铺名称和注册用的手机号；
4. 应用版本（**我的** 页面最下面的「版本」）。
