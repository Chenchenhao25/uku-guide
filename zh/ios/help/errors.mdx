## 登录和账号

| 提示 | 意思 | 怎么办 |
| --- | --- | --- |
| 电话号码或密码错误。 | 号码或密码不对 | 重新核对；用 **忘记密码？** |
| 请输入电话号码。 / 请输入密码。 | 有字段空着 | 补上 |
| 无效的电话号码。 | 格式不对 | 去掉空格和符号 |
| 号码的国家区号与所选国家不一致。 | 国家选错了 | 改国家或改号码 |
| 不支持的国际区号。 | 只支持 +39 / +34 / +54 | 换一个支持的号码 |
| 号码长度与所选国家不符。 | 位数不对 | 核对位数 |
| 此号码已注册，请使用登录。 | 已经有店铺了 | 去 **登录** |
| 电话号码未注册 | 这个号码没有店铺 | 先注册 |
| 验证码无效，请重试。 | 验证码填错 | 核对短信 |
| 验证码无效。请请求新验证码。 | 验证码过期 | **重新发送** |
| 尝试次数过多，请等待几分钟后再试。 | 请求太密集 | 等几分钟 |
| 密码长度至少为 6 位。 | 密码太短 | 换长一点的 |
| 推荐码必须是 6 位数字。 | 推荐码格式错 | 填 6 位数字或留空 |
| 设备不支持 | 手机太旧（需 A12 / iOS 14 以上） | 换较新的 iPhone |
| 账号有问题 | 账号被锁 | 点 **前往联系方式** 找客服 |
| 已在另一台设备上登录 | 被另一台设备挤下线 | **返回登录** 重新登录 |
| 未经授权的访问。 / 访问被拒绝。 | 登录状态失效 | 重新登录 |
| `Unauthorized. Please sign in again.` | 同上（英文） | 重新登录 |

## 网络和服务器

| 提示 | 意思 | 怎么办 |
| --- | --- | --- |
| 无网络连接 / 显示上次连接时的数据 | 离线状态，只能看不能改 | 打开网络 |
| 连接错误。请检查网络连接并重试。 | 请求时网断了 | 检查网络重试 |
| 服务器错误。请稍后重试。 | 我们这边的故障 | 等几分钟；持续就找客服 |
| 发生错误，请重试。 | 通用错误 | 重试 |
| 加载错误 | 列表没加载出来 | 下拉刷新或重新打开 |
| %d 秒后重试。 | 操作太密集 | 等提示的秒数 |
| `Rate limit exceeded. Retry after N seconds.` | 同上（英文） | 等 N 秒 |

## 做单页海报

| 提示 | 意思 | 怎么办 |
| --- | --- | --- |
| 请输入商品名称。 | 名称空着 | 填 **商品名称** |
| 请输入现价。 | 价格空着 | 填 **现价** |
| 请输入有效的原价，或留空此字段。 | 原价里有不是数字的内容 | 改正或清空 |
| 请添加商品图片。 | 没有照片 | 拍照、选图或扫条码 |
| 请先选择或填写商品后再继续。 | 没选商品来源 | 选一种输入方式 |
| 请先选择传单。 | 选了「从电子选择」却没选传单 | 先选一张传单 |
| 上传图片时出错： | 照片没传上去 | 换稳定网络或缩小照片 |
| 无法生成图片。 / 无法转换图片。 | 海报没生成成功 | 退出编辑器重新进 |
| 无法保存传单，请重试。 | 保存失败 | 检查网络重试 |
| 所选图片中未检测到条码。 | 相册照片里没有条码 | 用相机现场扫 |
| 未找到此条码对应的商品 | 数据库里没这个商品 | 手工填名称和照片 |
| 搜索时出错： | 查商品失败 | 重试 |
| 没有可裁剪的产品图片 | 还没加照片就点了裁剪 | 先加照片 |
| 无法加载图片进行裁剪： | 图片没下载下来 | 联网重试 |
| 已存在相同位置的布局。 | 新布局和旧的一模一样 | 先移动元素再存 |
| 默认布局不可更新 | 模板自带布局改不了 | 先 **新建布局** |
| 未找到商店 ID。 | 店铺资料没加载 | 重启应用或重新登录 |
| 请先在个人资料中设置店铺地址。 | 地址还空着 | **我的 → 编辑资料 → 地址** |
| `camera_permission_denied` | 相机权限被拒绝（没翻译） | 设置 > UKU 里打开相机 |
| `photo_library_permission_denied` | 相册权限被拒绝（没翻译） | 设置 > UKU 里打开照片 |

## 打印和相册

| 提示 | 意思 | 怎么办 |
| --- | --- | --- |
| 请至少选择一张传单进行打印。 | 一张都没选 | 先选中海报 |
| 图片不可用 | 图片没下载 | 联网后重新打开 |
| 打印已发送 | 成功提示 | — |
| 已保存到相册 | 成功提示 | — |
| 请在设置中允许访问照片以保存。 | 保存权限被拒绝 | 设置 > UKU > 照片 |
| 没有可保存到相册的内容页面。 | 页面是空的 | 先加内容 |
| 要编辑此传单，请在应用中打开传单部分。 | 这是数字传单 | 去 **传单** 标签 |

## 电视

| 提示 | 意思 | 怎么办 |
| --- | --- | --- |
| 连接超时，请重试。 | 配对代码过期 | 在电视上刷新 tv.uku.to 再扫 |
| 设备连接成功！ | 成功提示 | — |
| 暂无连接设备 | 还没配对电视 | **连接电视** 扫码 |
| 暂无可添加到电视的横版单页传单。 | 只有横版能上电视 | 做一张 **横向** 海报 |
| 建议使用横向 1920x1080（16:9）。 | 图片比例不对 | 先裁成 16:9 |
| 已过期 | 海报有效期到了 | 改海报的日期 |

## 客户、商品、资料

| 提示 | 意思 | 怎么办 |
| --- | --- | --- |
| 请输入客户姓名。 / 请输入客户电话号码。 | 字段空着 | 补上 |
| 此电话号码已存在。 | 客户重复 | 搜一下现有客户 |
| 名称、原价和优惠价为必填项 | 传单商品没填全 | 三项都要填 |
| 请输入传单标题。 | 标题空着 | 填 **标题** |
| 必填字段 / 名称为必填项 | 资料没填全 | 补上 |
| 无法同步设置 | 设置没保存到服务器 | 联网重试 |
| 部分缓存文件未能清理 | 清理缓存没完全成功 | 再清一次 |
| 应用缓存已清理 | 成功提示 | — |
| 暂无模版缓存，请重新打开应用或等待加载。 | 模版没下载 | 联网重新打开应用 |

## 额度

| 提示 | 意思 |
| --- | --- |
| 今日额度已用完 | 今天的单页海报额度用完了，明天恢复 |
| 已达到套餐限制 | 总量限制，要先腾地方 |
| 当前套餐已达到 %d 张数字传单的限制。 | 删掉旧传单 |
| 当前套餐已达到此传单 %d 个商品的限制。 | 拆成两张传单 |
| 当前套餐已达到 %d 张自定义电视图片的限制。 | 删掉不用的电视图片 |
| 当前套餐已达到 %d 个未完成或处理中待办项的限制。 | 处理掉待办 |

详见[额度用完了](/zh/ios/help/limits)。

## 订阅

| 提示 | 意思 | 怎么办 |
| --- | --- | --- |
| 暂无可用订阅，请稍后重试。 | 价格没加载 | **刷新状态与订阅** |
| 网络未连接或不稳定。 | 网络问题 | 换网络重试 |
| App Store 未能完成操作。 | Apple 那边出错 | 稍后重试 |
| 此设备已关闭 App 内购买。 | 系统限制 | 屏幕使用时间里打开 |
| 此订阅在你的 Apple 账号所在国家或地区不可用。 | Apple ID 国家不对 | 用对应国家的账号 |
| 正在验证购买。我们会自动重试，无需再次购买。 | 正在登记 | **等待，不要再买** |
| 暂时无法记录你的购买。付款是安全的 | 服务器没记下 | 点 **刷新状态与订阅** |
| 购买正在等待 Apple 批准。 | 家长批准 | 等对方同意 |
| 无法验证 Apple 购买，访问权限未更改。 | 验证失败 | 联系客服 |
| 此 Apple ID 已有关联其他店铺的 UKU 订阅。 | 一个 Apple ID 只能绑一家店 | 换 Apple ID 或找客服 |
| 此订阅已关联其他 UKU 店铺。 | 恢复错了店铺 | 登录购买时的店铺 |
| 你的店铺已有 Pro。 | 客服手动给的 Pro | 到期后再订阅 |
| 你的 Apple 订阅已生效。 | 已经是 Pro | 用 **管理订阅** |
| 购买功能暂未开放。 | 服务器暂时关闭了购买 | 稍后再试 |
| 请在 Apple 账号设置中检查付款方式。 | 付款方式有问题 | 更新银行卡 |
| 自动续订已关闭。 | 已取消续订 | 到期前仍可用 |
| 购买已记录，店铺状态已更新。 | 成功 | — |

## 网页版授权

| 提示 | 意思 | 怎么办 |
| --- | --- | --- |
| 二维码无效或已过期 | 二维码过期 | 刷新 web.ukuapp.com 再扫 |
| 无效的网页登录二维码 | 扫错了二维码 | 扫电脑页面上的那个 |
| 网页登录已拒绝 / 未授权任何访问 | 刚才点了拒绝 | 重新扫并点 **批准** |

## ITO 收银机

| 提示 | 意思 | 怎么办 |
| --- | --- | --- |
| 请输入有效的意拓地址。 | IP 格式不对 | 重新从收银机拄 |
| 意拓只接受最多 13 位的数字条码。 | 条码不支持 | 手工输入 |
| 意拓收银机响应异常。 | 收银机关了、Wi-Fi 不同或 IP 变了 | 检查 Wi-Fi 和 IP |

## 应用更新

**有可用更新** — App Store 上有新的 UKU 版本可用。选 **立即更新** 或 **稍后**。建议更新：新版本修正了已知问题。
