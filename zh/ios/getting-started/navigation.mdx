第一次登录 UKU，您可能会觉得功能很多，不知道从哪里开始。其实 UKU 的界面设计得很直观，底部只有五个主要入口。只要记住每个入口是做什么的，就能快速找到您需要的功能。

## 底部五个主入口

UKU 底部有一条导航栏，从左到右分别是：

| 入口 | 图标 | 用途 |
| --- | --- | --- |
| **首页** | 房子形状 | 打开常用工具、查看最近内容、进入电视管理 |
| **优惠** | 标签形状 | 查看和管理您保存的所有单页海报 |
| **创建** | 加号按钮 | 开始制作新的内容：单页海报、数字海报等 |
| **传单** | 纸张形状 | 管理数字海报和多页海报 |
| **我的** | 人形图标 | 修改店铺信息、设置偏好、查看订阅状态 |

### 首页：工作的起点

首页是您每天打开 UKU 最常用的地方。这里汇集了各种快捷入口：

- **最近内容**：您最近编辑或查看过的海报会显示在这里，方便继续未完成的工作
- **电视管理**：进入店内电视的设置页面，管理屏幕播放内容
- **商品清单**：查看待处理的商品任务，把记录好的商品做成海报
- **客户通讯录**：管理客户姓名和电话
- **资源管理**：查看和保存店铺相关的二维码、宣传材料
- **模板管理**：控制哪些海报模板显示在编辑器里，隐藏不常用的
- **网页版入口**：扫码授权电脑登录 UKU 网页版，制作多页海报
- **客服联系**：遇到问题从这里找到帮助渠道

首页右上角通常还有一个铃铛图标，显示 UKU 给您的重要通知，比如功能更新或者账户提醒。

### 优惠：您的海报仓库

所有保存好的单页海报都会出现在这里。您可以：

- 按商品名称搜索海报
- 用"全部"、"横版"、"竖版"筛选查看
- 点击任意海报查看详情、修改、分享或删除

<Tip>
  如果找不到某个海报，先检查顶部搜索框里是否还有文字，以及筛选条件是不是选成了"横版"或"竖版"。
</Tip>

### 创建：开始新工作

点击中间的加号按钮，UKU 会问您想做什么：

- 做单页海报（竖版或横版）
- 做数字海报（在线页面）
- 其他根据您订阅等级可用的选项

这是每次制作新内容的起点。

### 传单：管理在线页面

这里管理的是数字海报和多页海报：

- **数字海报**：包含多个商品的在线页面，可以复制链接发给客户
- **多页海报**：点击后会引导您到网页版编辑器，需要在电脑上继续操作

### 我的：店铺和账户设置

这里管理您店铺的基本信息和应用偏好：

- 修改店名、地址、logo
- 设置语言、货币符号、税率
- 调整打印和编辑器的默认选项
- 查看订阅状态、购买或管理 Uku Pro
- 清理缓存、退出登录、删除账号

## 下拉刷新

在很多列表页面，比如优惠、传单、商品清单，您可以把屏幕往下拉一下然后松手。这个操作叫"下拉刷新"，作用是重新加载最新数据。

<Info>
  下拉刷新只是更新页面上的信息，不会创建新内容，也不会续费您的订阅。如果某个海报刚保存但在列表里看不到，试试下拉刷新。
</Info>

## 界面操作小技巧

| 您想做的 | 操作方法 |
| --- | --- |
| 快速回到顶部 | 在列表页面，点击屏幕最上方的状态栏（显示时间的地方） |
| 返回上一页 | 从屏幕左侧边缘向右滑动，或者点击左上角的返回箭头 |
| 取消当前操作 | 点击页面空白处，或者找"取消"、"关闭"按钮 |
| 保存内容 | 编辑完成后找"保存"或"完成"按钮，不要直接退出 |
