第一次登录 UKU，您可能会觉得功能很多。其实界面很简单：底部一共只有 **4 个标签**，加上中间那个 **创建** 按钮。记住这五个入口，就能找到 UKU 的全部功能。

## 底部的五个入口

| 位置 | 名称 | 用途 |
| --- | --- | --- |
| 左 1 | **首页** | 查看 UKU 的通知、快速创建、继续最近的工作、打开"更多功能" |
| 左 2 | **优惠** | 您保存的所有单页海报（竖版和横版），也是批量打印的入口 |
| 中间 | **创建 +** | 开始做新的单页海报：横向 / 竖向 / 多页 |
| 右 1 | **传单** | 数字传单：多个商品的在线页面，有公开链接 |
| 右 2 | **我的** | 店铺资料、设置、套餐限制、权限、账户 |

<Note>
  **单页海报**（优惠）和 **数字传单**（传单）是两样不同的东西：前者是一张图片，可以打印、发到群里、投到电视上；后者是一个网页链接，客户点开能看到很多商品。
</Note>

## 首页：每天的起点

首页从上到下有四块内容：

1. **通知**：来自 UKU 的消息和重要通知。没有新消息时显示"暂无新消息"。
2. **制作你的传单**：四个创建入口——竖版单页、横版单页、多页传单、数字传单。
3. **继续 / 你制作的传单**：最近保存的内容，点"继续"接着做，点"查看全部"进入完整列表。
4. **更多功能**：八个工具，见下表。

<Frame caption="首页下半部分：更多功能的八个工具">
  <img

| 更多功能 | 作用 |
| --- | --- |
| **电视投屏管理** | 店内电视播放什么，以及连接电视 |
| **客户列表** | 客户姓名和电话 |
| **联系客服** | 微信客服群、专属客服二维码、WhatsApp |
| **资源管理** | 客户注册二维码、A4 海报 |
| **网页版登录授权** | 扫码让电脑登录 web.ukuapp.com |
| **管理模版** | 控制创建海报时能看到哪些模版 |
| **批量打印** | 一张 A4 纸上打印多个价格牌 |
| **商品待办** | 先扫条码记下商品，以后再做海报 |

<Warning>
  首页的 **通知** 只是 UKU 在应用里的公告栏，**不是手机推送通知**。UKU 不会在您不打开应用时给您发系统提醒，所以重要的事情请自己定期打开看一眼。
</Warning>

## 创建 +：选择格式

点中间的 **创建 +**，会弹出 **选择格式**：

<Frame caption="选择格式：横向、竖向、多页">
  <img
    src="https://img-v2.ukuapp.com/docs/guida-ios/zh/w600/03-menu-crea.webp"
    alt="选择格式 横向 竖向 多页"
    className="mx-auto"
    style={{ width:"38%" }}
  />
</Frame>

| 选项 | 得到什么 | 什么时候用 |
| --- | --- | --- |
| **横向** | 横的单页海报 | 要投到店内电视上（**只有横向的能上电视**），或者贴在宽的位置 |
| **竖向** | 竖的单页海报 | 打印贴货架、发微信、发朋友圈 |
| **多页** | 打开一页说明，告诉您去电脑上做 | 多页宣传册，要在电脑浏览器里完成 |

<Tip>
  拿不准就选 **竖向**：打印和分享最常用的就是它。想上电视再做一张 **横向** 的。
</Tip>

## 优惠：您的海报仓库

所有保存好的单页海报都在这里（"我的优惠"）。您可以：

- 用上方的 **搜索优惠** 按商品名称查找；
- 用 **全部 / 横向 / 纵向** 筛选；
- 点任意一张打开 **优惠详情**：打印、保存到相册、编辑优惠、分享、发送到电视、删除；
- 点右上角 **管理** 进入多选，做 **批量打印**。

<Tip>
  找不到某张海报时，先看看搜索框里是不是还留着字，筛选是不是停在"横向"或"纵向"。
</Tip>

## 传单：在线页面

**传单** 标签里是数字传单：一个标题下面放很多商品，保存后得到一个 `view.uku.to` 的链接，复制给客户就能打开。状态分 **在线** 和 **草稿**，草稿客户看不到。

## 我的：店铺和账户

- 套餐（免费版 / Pro 版）和 **管理订阅**
- **设置**：APP语言、货币符号、税率、传单语言
- **套餐限制**：每项还剩多少
- **数字传单** 和 **传单偏好**：小数、不含税价格、A4 边距等
- **权限**：相机、照片图库、保存到照片
- **支持** 和 **账户**：联系客服、清理应用缓存、退出登录、删除账户

## 一些操作习惯

| 您想做的 | 操作方法 |
| --- | --- |
| 刷新列表 | 在列表页往下拉一下再松手 |
| 返回上一页 | 从屏幕左边缘往右滑，或点左上角的返回箭头 |
| 放弃当前编辑 | 点 **取消** |
| 保存 | 编辑完点 **保存**（修改已有内容时是 **更新**），不要直接退出 |
