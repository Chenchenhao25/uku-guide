做海报之前，先把店铺资料填好。地址、货币符号和税率会直接印在海报上，改一次以后就不用管了。

全部设置都在底部的 **我的** 标签里。

## 第一步：店铺资料

**我的 → 编辑资料**，填写：

| 字段 | 说明 |
| --- | --- |
| **商店名称** | 显示在应用顶部和部分海报模版上 |
| **地址** | 想在海报上显示店铺地址，这里必须先填 |
| **Logo 链接** | 可以不填；有的话会用在海报和数字传单上 |
| **推荐码（选填）** | 只有推荐人给了您 6 位数字才填 |

填完点 **保存更改**。

<Note>
  在做海报时想勾「在传单上显示店铺地址」，却看到 **请先在个人资料中设置店铺地址。**，就是这里的地址还空着。
</Note>

## 第二步：设置

**我的 → 设置**：

<Frame caption="设置：APP语言、货币符号、税率、传单语言">
  <img
    src="https://img-v2.ukuapp.com/docs/guida-ios/zh/w600/35-profilo-impostazioni.webp"
    alt="设置页面"
    className="mx-auto"
    style={{ width:"38%" }}
  />
</Frame>

| 设置 | 作用 | 建议 |
| --- | --- | --- |
| **APP语言** | 应用界面的语言 | 中文（这也是默认语言） |
| **货币符号** | 价格前后显示的符号 | 按您所在国家选，例如 € |
| **税率** | 用来算「不含税价格」 | 填您店里适用的百分比 |
| **传单语言** | **印在海报上**的文字语言（有效期等） | 按客户看得懂的语言选，不一定跟界面语言一样 |
| **ITO 意拓科技集成** | 连接意拓收银机（需要同一个 Wi-Fi） | 没有这台收银机就不用管 |

<Warning>
  **APP语言** 和 **传单语言** 是两回事：前者是您自己看的界面，后者是客户在海报上看到的字。给意大利客人看的海报，传单语言要选意大利语。
</Warning>

## 第三步：传单偏好

**我的** 往下滑，有 **数字传单** 和 **传单偏好** 两块。

<Frame caption="数字传单与传单偏好">
  <img
    src="https://img-v2.ukuapp.com/docs/guida-ios/zh/w600/36-profilo-preferenze.webp"
    alt="数字传单和传单偏好设置"
    className="mx-auto"
    style={{ width:"38%" }}
  />
</Frame>

| 开关 | 打开之后 |
| --- | --- |
| 隐藏价格小数（数字传单） | 在线传单上的价格不显示小数 |
| 显示不含税价格 | 按 **税率** 算出不含税价一起显示 |
| **记住单页海报设置** | 下次新建海报时，沿用上一次的模版和样式 |
| **从相册扫码** | 可以从相册里的照片识别条形码，不用现场扫 |
| **A4 边距** | 打印时留安全边距，**防止价格牌被裁掉** |

<Tip>
  打印出来发现边上被切掉了？打开 **A4 边距**，再打一次。
</Tip>

## 第四步：权限

**我的 → 权限** 显示三个权限的状态，可以直接在这里请求，或者跳到系统设置里打开。

<Frame caption="权限：相机、照片图库、保存到照片">
  <img
    src="https://img-v2.ukuapp.com/docs/guida-ios/zh/w600/37-profilo-permessi.webp"
    alt="权限页面"
    className="mx-auto"
    style={{ width:"38%" }}
  />
</Frame>

| 权限 | 不给会怎样 |
| --- | --- |
| **相机** | 不能拍照、不能扫条形码 |
| **照片图库** | 不能从相册选商品图片 |
| **保存到照片** | 不能把做好的海报保存到相册 |

<Warning>
  在海报编辑器里，如果相机或相册权限被拒绝，**点了按钮什么都不会发生，也没有提示**。遇到「点了没反应」，先来这里看看状态是不是 **已拒绝**。详见[照片、相机、扫码](/zh/ios/help/photo)。
</Warning>

## 看看还剩多少额度

**我的 → 套餐限制** 显示免费版每项还剩多少：今日单品传单、数字传单、每张传单商品数、自定义电视图片、未完成条码待办。Pro 版这里显示 **无限制**。
