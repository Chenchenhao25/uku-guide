UKU 是一款专门为店铺设计的 iOS 应用。它能帮您快速制作促销海报、管理商品信息，还能把优惠内容展示到电视屏幕上。不管您是开便利店、水果店还是服装店，只要会用手机拍照，就能做出漂亮的海报。

## UKU 能帮您做什么

UKU 的核心功能围绕一个简单思路：您输入商品信息，UKU 帮您做成好看的宣传材料。具体来说，您可以：

<CardGroup cols={2}>
  <Card title="单页海报" icon="image">
    为单个商品制作竖版或横版海报图片，适合发朋友圈、打印贴货架或发到微信群。
  </Card>

  <Card title="数字海报" icon="globe">
    把多个商品汇总成一个在线页面，生成链接发给客户，客户点开就能看到所有优惠。
  </Card>

  <Card title="多页海报" icon="files">
    在电脑上使用网页版编辑器，制作更复杂的多页宣传材料。需要在手机 UKU 上扫码授权。
  </Card>

  <Card title="店内电视" icon="tv">
    把做好的海报投放到店铺电视屏幕上，自动轮播，吸引进店顾客注意。
  </Card>

  <Card title="商品清单" icon="list-checks">
    先扫描或录入商品信息，存成待办清单，有空时再慢慢做成海报，不耽误卖货。
  </Card>

  <Card title="客户通讯录" icon="users">
    记录客户姓名和电话，方便日后联系和发送优惠信息。
  </Card>
</CardGroup>

## 如何选择功能

您不需要一次学会所有功能。根据您当下的需求，选择对应的功能即可：

| 您的需求 | 使用功能 | 得到的结果 |
| --- | --- | --- |
| 推广一个商品 | 单页海报 | 一张竖版或横版的优惠图片 |
| 一张纸打印多个海报 | 多图打印 | 一页纸上排好多个已保存的海报 |
| 把多个优惠汇总到网上 | 数字海报 | 一个可以通过链接打开的在线页面 |
| 做更复杂的多页宣传册 | 网页版编辑器 | 在电脑上继续编辑多页内容 |
| 在电视屏幕上展示优惠 | 店内电视 | 一组自动轮播的海报和图片 |
| 先记录商品，以后再做海报 | 商品清单 | 一份待处理的商品任务列表 |
| 记录客户联系方式 | 客户通讯录 | 一份客户姓名和电话的名单 |

## UKU 不是什么

UKU 专注于帮您做宣传材料，它不是以下这些工具：

- **收银系统**：UKU 不会帮您算账、收款或打印小票
- **库存管理**：UKU 不会记录您店里还剩多少货
- **会计软件**：UKU 不会做账、报税或统计营业额

<Info>
  数字海报只是展示商品和价格的在线页面，客户点开链接后不能直接在页面里下单付款。如果您需要在线收款，请使用其他专门的电商平台。
</Info>
