UKU 是专门给店铺做的 iPhone 应用。您输入商品名称和价格，拍一张照片，UKU 把它变成一张好看的促销海报——可以打印贴货架、发到微信、也可以投到店里的电视上。

不管是便利店、水果店还是服装店，会用手机拍照就会用 UKU。

## UKU 能帮您做什么

<CardGroup cols={2}>
  <Card title="单页海报（价格牌）" icon="image">
    给一个商品做一张竖版或横版图片，写上原价和现价。打印、发群、投电视都行。
  </Card>

  <Card title="批量打印" icon="printer">
    一张 A4 纸上排 1、2、4、9 或 16 张已经保存的价格牌，一次打印一整叠。
  </Card>

  <Card title="数字传单" icon="globe">
    把很多商品放进一个在线页面，得到一个链接，发给客户就能看到全部优惠。
  </Card>

  <Card title="店内电视" icon="tv">
    把横版海报投到店里的电视上自动轮播，还能上传自己的图片。
  </Card>

  <Card title="商品待办" icon="list-check">
    忙的时候先扫条码把商品记下来，有空再补名称、图片和价格，直接做成海报。
  </Card>

  <Card title="客户与二维码" icon="users">
    记录客户姓名和电话；打印一张带二维码的 A4 海报，让客户自己扫码登记。
  </Card>
</CardGroup>

## 我该用哪个功能

| 您想做的事 | 用哪个 | 得到什么 |
| --- | --- | --- |
| 推一个商品 | 单页海报（竖向） | 一张竖版图片，适合打印和发微信 |
| 在店里电视上轮播 | 单页海报（**横向**） | 一张横版图片，可以发送到电视 |
| 一次打印很多价格牌 | 批量打印 | 一张 A4 上多个价格牌 |
| 把一堆优惠发给客户 | 数字传单 | 一个 `view.uku.to` 链接 |
| 做多页宣传册 | 网页版（电脑上） | 在浏览器里编辑的多页传单 |
| 先记下商品，以后再做 | 商品待办 | 一份待处理清单 |
| 让客户留下联系方式 | 资源管理里的注册二维码 | 客户自己扫码登记 |

<Warning>
  **只有横向的单页海报能投到电视上。** 竖向的做得再好也不会出现在电视播放列表里。这是最容易搞错的一点。
</Warning>

## UKU 不是什么

- **不是收银系统**：不算账、不收款、不打小票。
- **不是库存管理**：不记录您店里还有多少货。
- **不是记账软件**：不做账、不报税、不统计营业额。

<Info>
  数字传单只是展示商品和价格的网页，客户不能在上面下单付款。需要在线卖货请用专门的电商平台。
</Info>

<Note>
  UKU **没有手机推送通知**。应用首页的"通知"是 UKU 在应用内部的公告栏，关掉应用就不会再提醒您。
</Note>

## 需要准备什么

| 条件 | 说明 |
| --- | --- |
| 设备 | iPhone 或 iPad，系统 iOS 17.6 以上；较老的机型可能无法通过安全验证 |
| 网络 | 登录、保存、模版、电视、订阅都需要联网；没网时只能查看上次的数据 |
| 手机号 | 注册要用意大利（+39）、西班牙（+34）或阿根廷（+54）的号码 |
| 屏幕方向 | 应用只有竖屏 |
