登录只需要两样东西：注册时用的 **电话** 和 **密码**。

## 登录

1. 打开 UKU。
2. 确认上方的国家正确，填 **电话** 和 **密码**。
3. 点 **登录**。

登录成功后，下次打开应用一般不用再输密码。

<Note>
  第一次登录需要联网。以后如果没有网络，应用会打开并显示上次的数据，顶部出现 **无网络连接** 的横幅，这时候不能保存新内容。
</Note>

## 忘记密码

1. 在登录页点 **忘记密码？**
2. 填手机号，点 **发送**，收短信验证码。
3. 填 **验证码** 并 **验证**。
4. 设置 **新密码**（至少 6 位），点 **重置密码**。
5. 看到「密码已成功更新！现在您可以使用新密码登录。」后，点 **返回登录** 用新密码进入。

<Warning>
  提示 **电话号码未注册** 表示这个号码还没有店铺。请先去 [注册](/zh/ios/getting-started/register)。
</Warning>

## 登录不进去时

| 提示 | 原因 | 怎么办 |
| --- | --- | --- |
| 电话号码或密码错误。 | 号码或密码不对 | 重新核对；不记得密码就用 **忘记密码？** |
| 请输入电话号码。 / 请输入密码。 | 有字段是空的 | 补上 |
| 无效的电话号码。 | 格式不对 | 去掉空格和符号 |
| 号码的国家区号与所选国家不一致，请更改国家或号码。 | 国家选错了 | 改国家或改号码 |
| 连接错误。请检查网络连接并重试。 | 没有网络 | 打开 Wi-Fi 或数据网络 |
| 服务器错误。请稍后重试。 | 服务器临时故障 | 过几分钟再试；一直这样请联系客服 |
| `Unauthorized. Please sign in again.`（英文） | 登录状态过期 | 重新登录一次 |
| **设备不受支持** | 手机太旧，无法通过 Apple 的安全验证 | 换一台较新的 iPhone |
| **账号有问题** | 账号被锁 | 点 **前往联系方式** 联系客服 |

## 「已在另一台设备上登录」

用同一个账号在另一台手机上登录后，这台会弹出：

> **已在另一台设备上登录** — 请重新登录以继续在此设备上使用。

点 **返回登录** 再登录一次就行。同时在两台设备上使用需要相应的套餐支持，否则后登录的那台会把前一台挤下线。

<Tip>
  店里有两个人要同时用 UKU，请联系客服确认您的套餐是否支持多设备。
</Tip>

## 退出登录

**我的 → 退出登录**。退出后本机保存的登录状态被清除，下次要重新输入手机号和密码。

<Warning>
  **删除账户** 和退出登录完全不同：删除是永久的，所有数据都会丢失。需要输入「删除」两个字和密码才能确认。
</Warning>
