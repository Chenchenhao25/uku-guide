注册一次，一个手机号对应一家店铺。整个过程分三步：手机号 → 验证码 → 店铺资料。

<Info>
  目前只支持 **意大利（+39）**、**西班牙（+34）** 和 **阿根廷（+54）** 的手机号。应用会根据您的位置自动选好国家，选错了可以手动改。
</Info>

## 第一步：手机号

1. 打开 UKU，在登录页点 **注册**。
2. 检查上方的国家是否正确，然后输入 **电话**（不用再输国家区号）。
3. 点 **发送**。

验证码会以短信发到这个号码。页面上会出现倒计时（**%d 秒后可重试**），倒计时结束才能点 **重新发送**。

## 第二步：验证码

在 **验证码** 里填收到的数字，点 **验证**。

| 提示 | 意思 | 怎么办 |
| --- | --- | --- |
| 验证码无效，请重试。 | 数字填错了 | 重新核对短信 |
| 验证码无效。请请求新验证码。 | 验证码已过期 | 点 **重新发送** 拿新的 |
| 尝试次数过多，请等待几分钟后再试。 | 短时间内试太多次 | 等几分钟再来 |
| 此号码已注册，请使用登录。 | 这个号码已经有店铺了 | 返回 **登录**，忘了密码就用 **忘记密码？** |

## 第三步：店铺资料

验证通过后填写：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| **商店名称** | 是 | 客户会在海报上看到 |
| **地址** | 建议填 | 想把地址印在海报上就必须填 |
| **密码** | 是 | 至少 6 位；输入时下面会显示强度：弱 / 中等 / 良好 / 强 |
| **Logo 链接 (可以不填)** | 否 | 有店铺 logo 的网址可以填 |
| **推荐码（选填）** | 否 | 别人推荐您用 UKU 时给的 **6 位数字** |

点 **完成注册**。注册成功后直接进入应用。

<Tip>
  密码请记牢。找回密码要重新收一次短信验证码。
</Tip>

## 注册时常见的提示

| 提示 | 原因 | 怎么办 |
| --- | --- | --- |
| 请输入电话号码。 | 手机号是空的 | 填上号码 |
| 无效的电话号码。 | 格式不对 | 检查有没有多余的空格或符号 |
| 号码的国家区号与所选国家不一致，请更改国家或号码。 | 号码开头的区号和选的国家对不上 | 改国家，或去掉号码里的区号 |
| 不支持的国际区号。请使用意大利、西班牙或阿根廷的号码。 | 只支持这三个国家 | 换一个支持的号码 |
| 号码长度与所选国家不符，请检查。 | 位数不对 | 例如西班牙是 +34 后面 9 位 |
| 密码长度至少为 6 位。 | 密码太短 | 换一个更长的 |
| 推荐码必须是 6 位数字。 | 推荐码格式不对 | 填 6 位数字，或者干脆留空 |
| **设备不受支持** / 此设备不支持所需的安全验证（Apple App Attest）。 | 手机太旧（需要 A12 芯片以上、iOS 14 以上） | 换一台较新的 iPhone |
| **账号有问题** / 如账号有问题，请联系客服。 | 账号在服务器端被锁 | 点 **前往联系方式** 联系客服 |

<Note>
  注册遇到解决不了的问题，登录页上的 **联系客服** 可以直接找到我们：注册有问题的话请联系客服。
</Note>
