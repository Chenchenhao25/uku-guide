## 按您想做的事来选

| 您想做的 | 用哪个功能 | 在哪里 |
| --- | --- | --- |
| 给一个商品做张价格牌 | [单页海报](/zh/ios/features/single-offer) | 创建 **+** → 竖向 / 横向 |
| 打印一叠价格牌 | [打印价格牌](/zh/ios/features/print) | 优惠 → 管理 → 批量打印 |
| 发一个链接给客户看全部优惠 | [数字传单](/zh/ios/features/digital-flyers) | 传单标签 |
| 店里电视自动轮播 | [店内电视](/zh/ios/features/tv) | 首页 → 电视投屏管理 |
| 忙的时候先把商品记下来 | [商品待办](/zh/ios/features/product-todos) | 首页 → 商品待办 |
| 记客户电话、让客户扫码登记 | [客户和二维码](/zh/ios/features/customers) | 首页 → 客户列表 / 资源管理 |
| 在电脑上做多页传单 | [网页版](/zh/ios/features/web) | 首页 → 网页版登录授权 |
| 解除免费版的额度限制 | [免费版和 Pro](/zh/ios/features/pro) | 我的 → 升级 UKU Pro |

## 三样最容易混淆的东西

<CardGroup cols={3}>
  <Card title="单页海报" icon="image">
    一个商品、一张图片。可以打印、保存到相册、分享，横版的还能上电视。保存在 **优惠** 标签里。
  </Card>

  <Card title="数字传单" icon="globe">
    很多商品、一个网页链接（view.uku.to）。客户在手机上打开看，不能打印成一张图。保存在 **传单** 标签里。
  </Card>

  <Card title="多页传单" icon="file-lines">
    多页的宣传册，**只能在电脑浏览器里做**。手机上点「多页」只会告诉您去电脑上操作。
  </Card>
</CardGroup>

<Warning>
  **只有横向的单页海报能发送到电视。** 做给电视看的，创建时就要选 **横向**。
</Warning>

## 免费版能用到什么程度

所有功能免费版都能用，只是有数量限制（**我的 → 套餐限制** 里随时能看）：

| 限制 | 含义 |
| --- | --- |
| 今日单品传单 | 今天还能做几张单页海报，**每天零点重新开始** |
| 数字传单 | 总共能有几张在线传单 |
| 每张传单商品数 | 一张数字传单里最多放几个商品 |
| 自定义电视图片 | 能上传几张自己的电视图片 |
| 未完成条码待办 | 商品待办里最多留几条没做完的 |

额度用完时会弹出 **今日额度已用完** 或 **已达到套餐限制**。详见[额度用完了](/zh/ios/help/limits)。

## UKU 没有的功能

- **手机推送通知**：首页的「通知」只是应用内的公告栏。
- **手机上做多页传单**：必须用电脑。
- **在应用里给客户群发 WhatsApp**：目前还没有。
- **收银、库存、记账**：UKU 不做这些。
