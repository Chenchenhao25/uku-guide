做好的单页海报可以直接从 iPhone 打印，用的是苹果自带的 AirPrint。有两种打印方式。

## 单张打印

**优惠** 标签 → 点开一张海报 → **打印**。

</Note>

## 批量打印：一张纸多个价格牌

更省纸的方式：一张 A4 上排好几个价格牌，一次打印一整叠。

<Frame caption="批量打印：选中要打印的价格牌，下面选布局">
  <img
    src="https://img-v2.ukuapp.com/docs/guida-ios/zh/16-stampa-multipla-selezione.png"
    alt="批量打印 选择"
    className="mx-auto"
    style={{ width:"38%" }}
  />
</Frame>

1. **优惠** 标签 → 右上角 **管理**（或者 首页 → **批量打印**）；
2. 点选要打印的海报，也可以 **全选**；
3. 下面的 **布局:** 选每页放几张：**1 / 2 / 4 / 9 / 16**；
4. 点 **打印（N）**。

<Frame caption="A4 预览：一页四张">
  <img
    src="https://img-v2.ukuapp.com/docs/guida-ios/zh/17-stampa-multipla-anteprima.png"
    alt="批量打印 A4 预览"

    style={{ width:"38%" }}

</Frame>

| 每页张数 | 适合 |
| --- | --- |
| 1 | 大幅海报，贴门口或走道 |
| 2 / 4 | 常规价格牌，贴货架 |
| 9 / 16 | 小标签，生鲜、零食、散装货 |

## 需要准备什么

| 需要 | 说明 |
| --- | --- |
| 一台 AirPrint 打印机 | 和 iPhone 连**同一个 Wi-Fi** |
| 已保存的海报 | 没保存的做不了批量打印 |
| 网络 | 海报里的图片如果还没下载过，要联网才能打印 |

<Tip>
  打印出来发现边缘被切掉：**我的 → 传单偏好 → A4 边距** 打开，再打一次。
</Tip>

## 不打印，存成图片

- 单张：优惠详情 → **保存到相册**；
- 批量：选好之后用 **保存**，整页存进相册。

存下来的图片可以发微信、发给复印店去印。

## 常见问题

| 提示 | 怎么办 |
| --- | --- |
| 请至少选择一张传单进行打印。 | 还没选中任何一张 |
| 图片不可用 | 图片没下载下来：联网后重新打开 |
| 请在设置中允许访问照片以保存。 | 去 设置 > UKU > 照片 打开权限 |
| 打印机列表是空的 | 打印机没开，或者不在同一个 Wi-Fi 上 |

更多见[打印问题](/zh/ios/help/print)。
