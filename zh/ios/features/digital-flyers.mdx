数字传单是一个 **网页**：一个标题下面放很多商品，保存后得到一个链接，发给客户，客户在手机上点开就能看到全部优惠。

## 和单页海报的区别

| | 单页海报 | 数字传单 |
| --- | --- | --- |
| 是什么 | 一张图片 | 一个网页链接 |
| 商品数 | 1 个 | 很多个 |
| 能打印吗 | 能 | 不能直接打印成一张图 |
| 能上电视吗 | 横版的能 | 不能 |
| 怎么给客户 | 发图片 | 发链接 |
| 能看到多少人看了吗 | 不能 | **能**（浏览次数） |

## 什么时候用

- 周末促销、节日促销，一次推十几个商品；
- 微信群里发一条链接比发十几张图干净；
- 想知道有多少人点开看了。

每张传单有：

- **标题**（例如：圣诞特惠）；
- **状态**：**在线**（客户能打开）或 **草稿**（只有您自己能看）；
- **有效期**；
- **模板**（页面的样式）；
- 一个可以 **复制** 的链接，形如 `view.uku.to/#/...`；
- **浏览** 次数。

## 需要准备什么

每个商品要有：**名称、原价、现价**（这三项必填），图片和描述可选。没有现成图片时，可以 **从单页海报导入** 已经做好的内容。

<Note>
  免费版对 **数字传单总数** 和 **每张传单的商品数** 都有限制，在 **我的 → 套餐限制** 里可以看到还剩多少。
</Note>

## 怎么做

1. **传单** 标签 → **新建传单**；
2. 填 **标题**，选 **状态**、**有效期类型** 和 **模板** → **保存传单**；
3. 进入详情，点 **添加产品**，每个商品填名称、原价、现价、图片 → **保存产品**；
4. 用 **调整顺序** 排先后；
5. 点 **复制** 拿到链接，发给客户；**预览** 可以自己先看一眼。

详细步骤见[创建海报](/zh/ios/digital-flyers/create)。

<Warning>
  状态是 **草稿** 时，客户点链接是看不到内容的。发出去之前先改成 **在线**。
</Warning>
