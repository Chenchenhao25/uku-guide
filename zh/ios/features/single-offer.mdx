单页海报就是店里贴的那张 **价格牌**：一个商品、一张照片、原价和现价。做好之后可以打印、发微信、保存到相册，横版的还能投到店内电视上。

这是 UKU 里用得最多的功能。

## 它长什么样

打开编辑器后，上半部分是 **实时预览**（改什么马上就能看到），下半部分是四个标签：

| 标签 | 在这里做什么 |
| --- | --- |
| **商品** | 商品名称、条形码、照片 |
| **价格** | 原价（可选）、现价、要不要显示折扣百分比 |
| **外观** | 选模版、布局、颜色、字体样式 |
| **信息** | 有效期、店铺地址、是否在电视上显示 |

## 什么时候用

- 某个商品做特价，要贴到货架上；
- 要发一张图到微信群或朋友圈；
- 要在店内电视上轮播（这时候必须选 **横向**）。

## 需要准备什么

| 需要 | 说明 |
| --- | --- |
| 商品名称 | 必填 |
| 现价 | 必填 |
| 一张照片 | 必填。可以拍照、从相册选，或者**扫条形码**让 UKU 自动找图 |
| 原价 | 选填，填了才能显示折扣 |
| 网络 | 模版和图片上传都需要联网 |

## 三种获取商品资料的方式

<CardGroup cols={3}>
  <Card title="手动输入" icon="keyboard">
    自己写名称，自己拍照。最灵活。
  </Card>
  <Card title="扫条形码" icon="barcode">
    扫一下包装上的条码，能找到的话名称和图片自动填好。
  </Card>
  <Card title="从已有内容复制" icon="copy">
    从电子选择（数字传单里的商品）或从单品选择（已有的海报）直接拿过来。
  </Card>
</CardGroup>

<Note>
  商品图片右边那三个按钮**只有图标没有文字**：剪刀是裁剪，条码框是扫码，相机是加照片。
</Note>

## 竖向还是横向

| | 竖向 | 横向 |
| --- | --- | --- |
| 适合 | 打印、贴货架、发微信 | 店内电视、宽的位置 |
| 能上电视 | 否 | **是** |
| 有效期设置 | 有 | 有，另外多一个「在电视上显示」 |

## 怎么做

完整步骤见[创建单个优惠](/zh/ios/single-offer/overview)。最短的路径是：

1. 点底部中间的 **创建 +** → 选 **竖向** 或 **横向**；
2. **商品**：写名称、加照片；
3. **价格**：写 **现价**（想显示折扣就再写 **原价（可选）**）；
4. **外观**：挑一个模版；
5. **保存**。

保存后的海报出现在 **优惠** 标签里。点开就能[打印、分享、发送到电视](/zh/ios/features/print)。
