如果您店里用的是 **意拓科技（ITO）** 的收银机，UKU 可以直接从收银机里取商品资料，扫完条码就不用再手工输名称。

**没有这台收银机的话，这个功能可以完全不管。**

## 需要准备什么

| 需要 | 说明 |
| --- | --- |
| 意拓收银机 | 软件要是最新版 |
| 同一个 Wi-Fi | **iPhone 和收银机必须连店里同一个 Wi-Fi** |
| 收银机的本地 IP | 从收银机的系统信息里拄 |

## 怎么配置

1. 在收银机的系统信息里点「系统更新」，把意拓软件更新到最新；
2. 复制窗口里的「本地IP」；
3. 手机上：**我的 → ITO 意拓科技集成**；
4. 把 IP 填进 **收银机本地 IP**，保存。

## 常见问题

| 提示 | 原因 | 怎么办 |
| --- | --- | --- |
| 请输入有效的意拓地址。 | IP 格式不对 | 重新从收银机上拄一遍 |
| 意拓收银机响应异常。 | 收银机关了、不在同一个 Wi-Fi，或者 IP 变了 | 检查 Wi-Fi，重新填 IP |
| 意拓只接受最多 13 位的数字条码。 | 这个条码意拓不支持 | 手工输入商品资料 |

<Note>
  路由器重启后收银机的 IP 可能会变。突然读不到商品了，先回收银机上看一眼 **本地IP** 是不是变了。
</Note>
