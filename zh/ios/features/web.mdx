手机上做单页海报很方便，但 **多页传单**（好几页的宣传册）屏幕太小做不了，要在电脑上用浏览器做。

<Note>
  在应用里点 **创建 + → 多页**，打开的只是一页说明，告诉您去电脑上做——手机上没有多页编辑器。
</Note>

## 怎么在电脑上登录

网页版**不用密码**，用手机扫码授权：

<Frame caption="网页版登录授权：在电脑上打开 web.ukuapp.com">
  <img
    src="https://img-v2.ukuapp.com/docs/guida-ios/zh/w600/30-accesso-web.webp"
    alt="网页版登录授权"
    className="mx-auto"
    style={{ width:"38%" }}
  />
</Frame>

1. 在电脑浏览器里打开 **web.ukuapp.com**，屏幕上出现一个二维码；
2. 手机上：**首页 → 网页版登录授权**；
3. 点 **扫描二维码**，对准电脑屏幕；
4. 手机上弹出 **授权网页登录？**，确认店铺名称后点 **批准**（不是您本人在操作就点 **拒绝**）；
5. 电脑上自动登录进入您的店铺。

<Warning>
  只在**您自己正在登录**的时候点 **批准**。没有预期的授权请求一律点 **拒绝**。
</Warning>

## 网页版能做什么

- 做和修改 **多页传单**（完整的宣传册）；
- 在大屏幕上排版，用鼠标拖拽更精确；
- 导入 Excel、CSV 等文件里的商品清单。

手机和电脑用的是**同一个店铺账号**，数据是通的。

## 常见问题

| 提示 | 怎么办 |
| --- | --- |
| 二维码无效或已过期 | 在电脑上刷新 web.ukuapp.com 再扫一次 |
| 无效的网页登录二维码 | 扫错了二维码（比如扫了电视的） |
| 网页登录已拒绝 | 刚才点了 **拒绝**：重新扫码并点 **批准** |

更多见[网页版授权问题](/zh/ios/help/web)。
