店里有一台能上网的电视或屏幕，就能拿来轮播 UKU 的优惠。不需要装任何盒子，用电视自带的浏览器打开一个网址就行。

## 需要准备什么

| 需要 | 说明 |
| --- | --- |
| 一台能上网、有浏览器的电视 | 智能电视、电脑接屏幕、平板都可以 |
| **横向** 的单页海报 | 竖版的不能上电视 |
| 网络 | 电视和手机都要联网 |

<Warning>
  **只有横向的单页海报能上电视。** 如果选内容时看到「暂无可添加到电视的横版单页传单。」，就是因为您做的都是竖版。
</Warning>

## 怎么连接电视

1. 在电视的浏览器里打开 **tv.uku.to** —— 屏幕上会出现一个二维码和一串代码；
2. 手机上：**首页 → 电视投屏管理 → 连接电视**；
3. 点 **扫描二维码或输入代码**，对准电视屏幕上的二维码（也可以 **或手动输入代码**）；
4. 等到出现 **设备连接成功！**，电视就出现在 **已连接设备** 里。

## 电视上放什么

在 **投屏** 页面里管理播放列表：

- **添加到电视 → 从优惠中选择**：把已有的横版海报放上去；
- **上传图片 → 从相册选择**：放自己的图片（建议 **1920×1080（16:9）**）；
- 每条可以单独开关（**在线 / 关闭**），过了有效期会显示 **已过期**；
- 每张停留的秒数在做海报时的 **信息** 标签里设（**电视展示时长**，3–3600 秒，默认 10）。

<Tip>
  做横版海报时，**信息** 标签里有一个 **在电视上显示** 开关。提前打开，保存后就直接进播放列表了。
</Tip>

## 常见问题

| 情况 | 原因 / 怎么办 |
| --- | --- |
| 连接超时，请重试。 | 代码过期：在电视上刷新 tv.uku.to 重新扫 |
| 暂无连接设备 | 还没配对过电视 |
| 电视上什么都不显示 | 播放列表是空的，或者内容都是 **关闭** / **已过期** |
| 图片被裁掉边 | 上传的图不是 16:9，先裁成横版 |

更多见[电视投屏问题](/zh/ios/help/tv)。
