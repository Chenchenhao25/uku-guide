UKU 里和客户有关的有两块：自己记录的 **客户列表**，和让客户自己扫码登记的 **注册二维码**。

## 客户列表

**首页 → 客户列表**。每个客户只有两项：**客户姓名** 和 **电话号码**。

<Frame caption="新客户：姓名 + 电话">
  <img
    src="https://img-v2.ukuapp.com/docs/guida-ios/zh/w600/27-cliente-nuovo.webp"
    alt="新客户表单"
    className="mx-auto"
    style={{ width:"38%" }}
  />
</Frame>

点 **新客户** 填好两项，再点 **保存客户信息**。同一个电话不能录两次（会提示 **此电话号码已存在。**）。

<Note>
  目前 UKU **不能在应用里给这些客户群发消息**。这份名单是您自己的通讯录，要联系客户请用微信、短信或电话。
</Note>

## 让客户自己登记

**首页 → 资源管理**，里面有您店铺专属的 **客户注册** 二维码。

<Frame caption="资源管理：客户注册二维码">
  <img
    src="https://img-v2.ukuapp.com/docs/guida-ios/zh/w600/32-risorse.webp"
    alt="资源管理"
    className="mx-auto"
    style={{ width:"38%" }}
  />
</Frame>

两种用法：

- 点 **保存** 把二维码存到相册，发微信或打印出来贴在收银台；
- 点 **打印 A4 海报 → 预览并打印**，直接打一张带二维码的 A4 海报。

<Frame caption="A4 海报预览">
  <img
    src="https://img-v2.ukuapp.com/docs/guida-ios/zh/w600/33-locandina-a4.webp"
    alt="A4 海报预览"
    className="mx-auto"
    style={{ width:"38%" }}
  />
</Frame>

<Warning>
  这张 A4 海报目前**只有意大利语版本**。客户看不懂的话，可以只用 **保存** 存下二维码，自己配上中文说明。
</Warning>

## 联系客服

**首页 → 联系客服**：里面有 **微信客服群** 和 **专属客服** 两个二维码（可以 **保存** 到相册），以及一个 **WhatsApp** 按钮作为备用联系方式。
