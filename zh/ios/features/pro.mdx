UKU 的免费版**不锁功能**：单页海报、数字传单、电视、客户、打印全都能用。区别在**数量**。

## 五项额度

在 **我的 → 套餐限制** 里随时能看到还剩多少：

| 额度 | 含义 | 什么时候恢复 |
| --- | --- | --- |
| **今日单品传单** | 今天还能做几张单页海报 | **每天重新开始** |
| **数字传单** | 总共能有几张 | 删掉旧的就释放 |
| **每张传单商品数** | 一张传单里最多放几个商品 | — |
| **自定义电视图片** | 自己上传的电视图片数 | 删掉旧的就释放 |
| **未完成条码待办** | 商品待办里没做完的条数 | 处理掉就释放 |

Pro 版这几项都显示 **无限制**。

## 额度用完时会看到什么

会弹出 **今日额度已用完** 或 **已达到套餐限制**，下面两个按钮：**升级 UKU Pro** 和 **确定**。点 **确定** 什么都不会发生，明天再继续就行。

## 订阅 Pro

1. **我的 → 升级 UKU Pro**（或限制提示里的同名按钮）；
2. 在 **选择订阅时长** 里选 **1 个月 / 3 个月 / 6 个月 / 12 个月**（时间越长每月越便宜）；
3. 点 **订阅 Pro**（符合条件时显示 **免费试用**），用 Face ID 或 Apple 账号密码确认；
4. 看到 **购买已记录，店铺状态已更新。** 就生效了。

<Warning>
  出现 **正在验证购买。我们会自动重试，无需再次购买。** 时，**千万不要再买一次**。等几分钟，或者点 **刷新状态与订阅**。
</Warning>

## 重要：一个 Apple ID 只能绑一家店

一个 Apple 账号的 UKU 订阅只能属于**第一家**用它购买的店铺。用同一个 Apple ID 给第二家店买时，应用会提前阻止：

> 此 Apple ID 已有关联其他店铺的 UKU 订阅。如需为本店铺订阅，请使用其他 Apple ID 或联系客服。

两家店都要 Pro，就用**两个不同的 Apple ID**，或者联系客服。

## 管理、恢复和取消

| 您想做的 | 怎么做 |
| --- | --- |
| 换时长、取消续订 | **我的 → 管理订阅**（会跳到 Apple 的订阅设置） |
| 换了手机，Pro 没了 | 付款页面里的 **恢复购买** |
| 买了但应用里还是免费版 | **刷新状态与订阅** |

<Note>
  取消续订后，Pro **到期之前一直能用**，页面上会写 **自动续订已关闭。** 和 **有效期至**。
</Note>
