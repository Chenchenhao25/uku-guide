上货的时候没工夫做海报：先把商品**扫一下记下来**，晚上或者不忙的时候再一次性做成价格牌。这就是 **商品待办**。

## 什么时候用

- 收货、上架的时候，手里忙但商品就在眼前；
- 一次要做十几张价格牌，想先把商品集齐；
- 有些商品要等老板定价，先记下来。

## 怎么用

1. **首页 → 商品待办**；
2. 点 **扫描条形码**，对着包装上的条码扫；应用会显示 **正在搜索...**，能找到的话名称和图片自动填好；
3. 可以连着扫好几个；
4. 有空时点开一条 → **编辑产品**，补上商品名称、原价、现价、商品图片 → **保存更改**；
5. 准备好了点 **创建传单** → 选 **横向** 或 **竖向**：编辑器会**带着这个商品的资料打开**。

## 需要准备什么

| 需要 | 说明 |
| --- | --- |
| 相机权限 | 扫条码要用相机 |
| 网络 | 扫完要去网上查这个条码对应的商品 |
| 真机 | 模拟器没有相机，扫不了 |

<Note>
  条码查不到时会显示 **未找到此条码对应的商品**。这不是故障：自己填名称、自己拍一张照片就行。
</Note>

<Warning>
  在这个页面里，如果您拒绝了相机或相册权限，屏幕上会出现一串英文 `camera_permission_denied` 或 `photo_library_permission_denied`。这是应用的一个小毛病，意思是**权限被拒绝了**：去 **设置 > UKU** 里打开就行。
</Warning>

## 免费版的限制

免费版对 **未完成条码待办** 的数量有上限。把已经做成海报的待办处理掉，额度就释放了。
