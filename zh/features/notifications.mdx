Uku 可以通过推送通知、电子邮件提醒和应用内消息让你保持信息同步。你可以完全控制接收的内容和时间，这样你就能保持更新而不会感到不堪重负。无论你是想要开启所有通知、仅保留必要提醒，还是完全静音，Uku 都能让你轻松按照自己想要的方式进行设置。

## 通知类型

Uku 通过不同渠道发送几类通知。以下是可用类型及其默认启用状态的概览：

| 类型 | 渠道 | 默认状态 |
| --- | --- | --- |
| 活动更新 | 推送 + 应用内 | 开启 |
| 每周摘要 | 电子邮件 | 开启 |
| 特别优惠 | 电子邮件 | 关闭 |
| 系统提醒 | 推送 + 应用内 | 开启 |

## 管理通知

你可以在几个简单的步骤中开启或关闭任何通知类别：

<Steps>
  <Step title="前往 设置 → 通知">
    轻点你的个人资料头像（右上角），选择 **设置**，然后轻点 **通知** 以打开通知偏好设置屏幕。
  </Step>
  <Step title="切换通知类别">
    使用每个类别旁边的切换开关来开启或关闭它们。更改会立即生效，应用内和推送切换无需手动保存。
  </Step>
  <Step title="单独管理电子邮件通知">
    对于电子邮件通知，轻点 **电子邮件偏好** 以打开专用屏幕，在那里你可以单独启用或禁用每种类型的电子邮件提醒。
  </Step>
  <Step title="轻点保存">
    完成电子邮件偏好的调整后，轻点 **保存** 以确认你的选择并返回主通知屏幕。
  </Step>
</Steps>

## 设备级权限

Uku 的推送通知还依赖于设备的操作系统授予应用权限。如果你从未收到过 Uku 的推送通知，或者它们突然停止了，你的设备可能已将其阻止。

<Info>
  **要在你的设备上重新启用推送通知：**

  - **iOS：** 前往手机的 **设置** → 向下滚动并轻点 **Uku** → 轻点 **通知** → 启用 **允许通知** 并选择你喜欢的提醒样式。
  - **Android：** 前往手机的 **设置** → **应用** → 轻点 **Uku** → 轻点 **通知** → 开启 **所有 Uku 通知**。

  一旦设备级权限恢复，Uku 的推送通知将根据你的应用内偏好自动恢复。
</Info>

<Tip>
  使用 **勿扰时段** 在夜间或其他安静时段自动静音 Uku 通知。前往 **设置 → 通知 → 勿扰**，然后设置开始和结束时间。通知将被保留并在安静时段结束后送达。
</Tip>
