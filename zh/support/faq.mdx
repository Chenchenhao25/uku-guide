在这里找到用户最常提出问题的即时答案。如果你在这里没有找到需要的内容，请访问我们的[常见问题排查](/support/common-issues)页面或[联系支持](/support/contact)。

<AccordionGroup>
  <Accordion title="如何更改应用语言？">
    前往**设置 → 语言**，从列表中选择你偏好的语言。应用将立即更新，无需重启。
  </Accordion>

  <Accordion title="Uku 是免费的吗？">
    是的 — Uku 提供免费计划，你可以无限期使用。付费计划（Pro 和 Premium）可解锁更多功能，例如高级分析、优先支持和扩展存储空间。前往**设置 → 订阅**以比较各计划。
  </Accordion>

  <Accordion title="如何重置密码？">
    在登录界面，点击**忘记密码**，输入与你的账户关联的电子邮件地址。你将在几分钟内收到密码重置链接。如果收件箱中没有收到，请检查你的垃圾邮件文件夹。
  </Accordion>

  <Accordion title="我可以在多台设备上使用 Uku 吗？">
    可以。在任何支持的设备上使用你的账户凭据登录，你的数据将自动同步。你可以同时使用的设备数量没有限制。
  </Accordion>

  <Accordion title="如何取消订阅？">
    前往**设置 → 订阅 → 取消计划**，按照屏幕上的提示操作。你对付费功能的访问将持续到当前计费周期结束。取消订阅不会删除你的账户。
  </Accordion>

  <Accordion title="Uku 支持哪些语言？">
    Uku 目前支持**英语、意大利语、法语、西班牙语、德语和葡萄牙语**。我们正在积极努力添加更多语言 — 请随时查看更新，或关注我们的发布说明以获取公告。
  </Accordion>

  <Accordion title="如何下载我的数据？">
    前往**设置 → 隐私 → 下载我的数据**。Uku 将准备一个包含你的账户信息和内容的文件，然后在 24 小时内将下载链接发送到你注册的电子邮件地址。
  </Accordion>

  <Accordion title="我可以在离线状态下使用 Uku 吗？">
    某些功能支持离线使用，让你无需互联网连接也能继续工作。你在离线状态下所做的任何更改都会保存在本地，并在你的设备重新联网时自动同步。
  </Accordion>

  <Accordion title="如何删除我的账户？">
    要永久删除你的账户，请联系我们的支持团队 [support@uku.app](mailto:support@uku.app) 并申请删除账户。请注意，**删除是永久性的** — 你的所有数据将被移除且无法恢复。
  </Accordion>

  <Accordion title="为什么我没有收到通知？">
    首先，检查 Uku 是否拥有在你的设备上发送通知的权限：

    - **iOS：** 前往设备**设置 → Uku → 通知**，确保通知已启用。
    - **Android：** 前往**设置 → 应用 → Uku → 通知**并将其打开。

    同时打开 Uku 并检查**设置 → 通知**，确认你的应用内通知偏好设置已正确配置。
  </Accordion>
</AccordionGroup>
