Uku 随时随地为你服务。在你的 iPhone 或 iPad 上安装，在 Android 设备上下载，或在任何现代网页浏览器中即时打开，无需安装。启动 Uku 只需片刻时间，你还可以在所有设备上无缝衔接，随时继续之前的操作。

## 如何获取 Uku

请按照以下针对你平台的说明进行操作：

<Tabs>
  <Tab title="iOS">
    1. 在你的 iPhone 或 iPad 上打开 **App Store**。
    2. 点击 **搜索** 标签页，在搜索栏中输入 **"Uku"**。
    3. 在搜索结果中找到官方 Uku 应用，然后点击 **获取**。
    4. 使用 Face ID、Touch ID 或你的 Apple ID 密码进行身份验证以确认下载。
    5. 安装完成后，点击 **打开** 启动 Uku。

    **最低要求：** iOS 14 或更高版本。
  </Tab>
  <Tab title="Android">
    1. 在你的 Android 设备上打开 **Google Play**。
    2. 点击顶部的 **搜索** 栏，输入 **"Uku"**。
    3. 在搜索结果中找到官方 Uku 应用，然后点击 **安装**。
    4. 接受所有请求的权限，等待下载完成。
    5. 点击 **打开** 启动 Uku。

    **最低要求：** Android 8.0（Oreo）或更高版本。
  </Tab>
  <Tab title="网页版">
    1. 在任何电脑或设备上打开你偏好的网页浏览器。
    2. 访问 [**app.uku.app**](https://app.uku.app)。
    3. Uku 网页应用会即时加载，无需安装或插件。
    4. 将页面添加书签，以便下次快速访问。

    **支持的浏览器：** Chrome、Firefox、Safari 和 Edge（各浏览器的最新两个主要版本）。
  </Tab>
</Tabs>

## 系统要求

| 平台 | 最低版本 |
| --- | --- |
| iOS | iOS 14 或更高版本 |
| Android | Android 8.0（Oreo）或更高版本 |
| 网页浏览器 | Chrome、Firefox、Safari 或 Edge（当前及上一个主要版本） |

<Note>
  Uku 在所有平台上均可免费下载和安装。部分高级功能可能需要付费订阅。你可以随时在应用内查看可用的方案。
</Note>
