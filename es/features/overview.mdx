## Novedades

Uku está mejorando constantemente. Nuevas funciones, mejoras y correcciones se implementan regularmente para que la app siga mejorando con el tiempo. Para ver qué ha cambiado, abre el registro de cambios dentro de la app navegando a **Ajustes → Acerca de → Novedades**. También puedes seguir las notas de lanzamiento oficiales para un historial completo de actualizaciones y cambios próximos.

<Tip>
  No sientas que necesitas aprender todo de una vez. Explora cada sección a tu propio ritmo. La mayoría de las funciones son lo suficientemente intuitivas para usarlas sobre la marcha.
</Tip>
